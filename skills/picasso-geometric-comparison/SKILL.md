# 毕加索几何抽象对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的几何抽象效果图配对，最终输出数量必须与输入数量相同、顺序一致。不要把不同原图放进同一张画布，也不要向用户额外输出中间生成图。

本技能默认使用毕加索 1930 年代人物画启发的具象抽象语言与中高抽象强度，但不依赖、下载、复制或打包任何经典画作。不要模仿某幅具体作品的构图、人物、标志性细节、签名或题材。

## 默认视觉语言

- **形体**：用少量有决定性的大色块重组主体，混合直线、折线、椭圆和流动曲线。允许正面与侧面视角在同一头部或物体中叠合，但不使用覆盖整幅画面的均匀三角网格。
- **抽象**：默认中高强度。锁定主体数量、姿态、占画面比例和识别锚点；允许五官、轮廓、肢体内部比例出现有目的的错位、旋转、压缩和夸张。
- **线条**：主要边界使用清楚、连续、粗细略有变化的黑色或深炭色轮廓。内部结构线要少而有力，不绘制密集细线、写实明暗排线或低多边形线框。
- **色彩**：使用有限但高纯度的平涂色组。优先从钴蓝、青绿、鲜红、橙、柠檬黄、草绿、粉、象牙白和黑色中选取 4–7 个主色；颜色承担形体分区，不受原照片固有色和写实光影约束。
- **空间**：压平透视，用重叠轮廓、大背景色带或与原图结构对应的装饰图案组织空间。背景可以简化，但不得添加新的场景或叙事物体。
- **表面**：保留不均匀的手绘油彩、蛋彩或水粉触感；色块总体平整、边界明确，不追求玻璃、塑料或三维渲染质感。

## 执行流程

1. 按用户上传顺序记录全部原图的本地绝对路径。不要按文件名或文件系统顺序重排。若无法取得每张图的独立本地路径，在开始生成前说明阻塞；不要把多张参考图一起传给生成工具。
2. 为每张原图建立独立临时目录。原始文件只读使用，不覆盖、不重命名，也不用重新生成的相似图片替代原图。
3. 每次只处理一张原图，并调用图像生成工具一次：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不要同时传入其他原图。
   - 不要让生成工具制作拼图、边框、标题或对照版式；它只生成当前原图对应的单张几何抽象效果图。
   - 默认使用下方“默认生成提示词”。用户明确指定其他强度时，再应用“抽象强度”中的覆盖规则。
4. 检查效果图：画幅方向和比例与原图一致；主体数量、姿态、占画面比例、位置、地平线和主要物体间关系仍可对应辨认。人物或动物至少保留物种、头身关系、标志性轮廓、五官数量和主要花纹；允许视角叠合和局部错位，但不得凭空增加眼睛、嘴、耳朵、肢体或主体。
5. 以下任一情况都视为失败并针对具体偏差重试，最多 2 次：主体不可辨认；宏观构图或物体数量变化；画幅比例超限；整幅画被切成均匀细碎三角形；仍像加了滤镜的照片；配色以浑浊棕灰为主；缺少明确粗轮廓和大色块；出现文字、签名、水印、Logo、画框或新物体。达到上限仍失败时继续处理其余输入，并在最终回复中准确说明未完成项。
6. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。脚本会校验比例、依据原图方向选择布局并输出 PNG；不要让图像模型生成原图区域。
7. 输出名优先使用 `<原文件名去扩展名>_picasso_comparison.png`。发生同名冲突时在后者末尾添加上传序号，绝不覆盖前一张成品。
8. 完成一张后立即自动继续下一张，不要在批处理中途请求确认。全部完成后，只向用户呈现按上传顺序排列的最终对照 PNG。中间效果图和临时文件不得作为成品呈现；仅清理本次创建的临时目录。

## 默认生成提示词

对每张原图单独使用以下内容，并明确当前参考图是唯一内容依据：

> 将这张参考照片转化为毕加索 1930 年代人物抽象语言启发的手绘画，但不要复制任何具体经典画作。严格保留原图的画幅比例、裁切范围、主体数量、姿态、占画面比例、主体位置、地平线和主要物体之间的关系，使原场景与主体仍能被立即辨认。使用中高抽象强度：以少量大而明确的不规则平面、椭圆、弧形和折线重组主体；允许把正面与侧面视角压进同一头部或物体，在内部有目的地错位、旋转、压缩和夸张局部比例，但必须保留物种、五官数量、标志性轮廓、主要花纹和姿态，不得增加、删除、替换或复制主体与器官。主要轮廓使用连续、醒目、粗细略有变化的黑色或深炭色结构线；内部线条少而有力。不要把整幅画均匀切成细碎三角形。使用 4–7 个高纯度主色组织形体，可从钴蓝、青绿、鲜红、橙、柠檬黄、草绿、粉、象牙白和黑色中依据画面关系选择；允许颜色脱离原照片固有色，用强冷暖或互补对比替代写实明暗。空间保持扁平，以重叠大轮廓、背景色带或与原图结构对应的简化装饰图案组织，不添加新场景。表面具有不均匀的手绘油彩、蛋彩或水粉触感，色块总体平整、边界明确。输出只包含单张抽象画并填满原始画幅；不要拼图、原图对照、留白边框、文字、标签、签名、水印、Logo 或原图中不存在的物体。避免低多边形 3D、均匀三角镶嵌、彩色玻璃、万花筒、剪贴画、卡通描边、摄影滤镜、写实三维阴影、塑料质感、过度锐化、棕灰浑浊配色和无法辨认的彻底解构。

如重试，只补充已经观察到的具体偏差，例如“当前结果是密集三角切面；改成少量大色块、粗黑连续轮廓和高纯度红黄蓝绿配色”，不要改写原图内容。

## 按主体调整

- **人物或动物肖像**：优先使用正侧面叠合、不同方向的眼鼻口轴线和非对称大色块。可以错位五官，但五官数量不变，表情、物种与身份锚点仍可辨认。
- **全身人物或动物**：优先用大弧线和椭圆压缩身体，以少量折线标记关节、衣褶或花纹；手、脚、爪、尾巴等末端不得丢失或增生。
- **建筑、车辆、静物或风景**：沿真实结构分成少量大平面，用夸张轮廓和高纯度色块改变空间表达；不要强行添加人脸式五官，也不要把天空、地面和主体统一切成同尺寸多边形。

## 抽象强度

- `克制`：保留接近原图的外轮廓和局部比例，主要通过粗轮廓、平涂色块和轻微错位表现抽象。
- `中高`：默认。锁定主体识别、姿态和宏观构图，明显叠合正侧面视角，以少量大色块重组五官、身体或结构，并使用高纯度对比色。
- `强烈`：仍锁定主体数量、位置、姿态和识别锚点，但允许更大幅度地错位内部比例、局部视角和色块节奏。不得增生器官或变成不可辨认的纯抽象。

未明确指定强度时始终使用 `中高`，不要询问。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow。

脚本固定执行这些版式约束：

- 横版：原图在上、效果图在下；竖版或正方形：原图在左、效果图在右。
- 两图显示尺寸完全相同，原图不缩放、不裁切、不调色；效果图仅在宽高比通过校验后调整到原图尺寸。
- 背景 `#F7F4EE`；四周留白和两图间距均为单张图短边约 4%。
- 外沿描边 `#E5E0D7`，粗细为短边约 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、签名、Logo 或水印。

脚本允许效果图与原图的画幅比例相对偏差不超过 0.5%。超过上限时重新生成效果图；不得通过裁切、明显拉伸、压缩或加边伪装成匹配比例。

## 完成检查

交付前核对：输入 N 张、输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；默认风格为 1930 年代人物式具象抽象、中高强度；效果图具有少量大色块、明确粗轮廓和高纯度配色，而非均匀细碎三角网格；主体仍可识别；方向布局正确；两图完整、等尺寸、无重叠；顺序与命名正确；所有成品均为高清 PNG。
