# 毕加索几何抽象对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的几何抽象效果图配对，最终输出数量必须与输入数量相同、顺序一致。不要把不同原图放进同一张画布，也不要向用户额外输出中间生成图。

本技能默认使用毕加索启发的合成立体主义视觉语法与中等抽象强度，但不依赖、下载、复制或打包任何经典画作。不要模仿某幅具体作品的构图、人物、标志性细节或题材。

## 执行流程

1. 按用户上传顺序记录全部原图的本地绝对路径。不要按文件名或文件系统顺序重排。若无法取得每张图的独立本地路径，在开始生成前说明阻塞；不要把多张参考图一起传给生成工具。
2. 为每张原图建立独立临时目录。原始文件只读使用，不覆盖、不重命名，也不用重新生成的相似图片替代原图。
3. 每次只处理一张原图，并调用图像生成工具一次：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不要同时传入其他原图。
   - 不要让生成工具制作拼图、边框、标题或对照版式；它只生成当前原图对应的单张几何抽象效果图。
   - 默认使用下方“中等抽象生成提示词”。用户明确指定其他强度时，再应用“抽象强度”中的覆盖规则。
4. 检查效果图：画幅方向和比例与原图一致；主体数量、全局轮廓、视点、主体位置、地平线、空间层级和主要物体间关系仍可对应辨认；允许局部结构被切分、扁平化和多视角重组，但不得增加、删除、移动或替换主要物体。
5. 若主体不可辨认、宏观构图漂移、主要物体数量变化、画幅比例超限，或出现文字、签名、水印、Logo、画框和新物体，针对具体偏差重试当前图片，最多重试 2 次。达到上限仍失败时继续处理其余输入，并在最终回复中准确说明未完成项。
6. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。脚本会校验比例、依据原图方向选择布局并输出 PNG；不要让图像模型生成原图区域。
7. 输出名优先使用 `<原文件名去扩展名>_picasso_comparison.png`。发生同名冲突时在后者末尾添加上传序号，绝不覆盖前一张成品。
8. 完成一张后立即自动继续下一张，不要在批处理中途请求确认。全部完成后，只向用户呈现按上传顺序排列的最终对照 PNG。中间效果图和临时文件不得作为成品呈现；仅清理本次创建的临时目录。

## 中等抽象生成提示词

对每张原图单独使用以下内容，并明确当前参考图是唯一内容依据：

> 将这张参考照片转化为毕加索启发的合成立体主义几何抽象画，但不要复制任何具体经典画作。严格保留原图的画幅比例、裁切范围、宏观构图、视点、主体数量、主体位置、全局轮廓、地平线、空间层级和主要物体之间的关系。主体必须能被立即辨认。允许在主体内部和次要细节中使用有限的多视角拼合、错位轮廓、交叠切面、扁平空间和不对称几何重组；将局部形体分解为互相咬合的角形、弧形和平面色块，但不得增加、删除、移动、替换或重新设计主要物体。使用手绘油画与拼贴感结合的表面：哑光平面色块、可见但克制的笔触、纸张般的层叠边缘和自然画布肌理。配色依据原图调整，优先使用赭石、陶土红、靛蓝、青绿、象牙白、炭灰和少量芥末黄；使用有节奏的深炭色结构线，但避免粗重卡通描边。只改变视觉语言、空间表达、颜色组织和表面质感，不改变场景语义。输出只包含单张抽象画并填满原始画幅；不要拼图、原图对照、留白边框、文字、标签、签名、水印、Logo 或原图中不存在的物体。避免随机多边形滤镜、低多边形 3D、彩色玻璃、万花筒、剪贴画、卡通、纯摄影滤镜、塑料质感、过度锐化、浑浊颜色和无法辨认的彻底解构。

如重试，只补充已经观察到的具体偏差，例如“车辆轮廓无法辨认；恢复其全局轮廓和原始位置，仅在内部做几何切面”，不要改写原图内容。

## 抽象强度

- `克制`：宏观和局部轮廓都高度接近原图；主要通过扁平色块、少量交叠切面和有限错位表现立体主义。
- `中等`：默认。锁定宏观构图和主体识别，允许局部多视角、错位轮廓与明显几何重组。
- `强烈`：仍锁定主体数量、全局轮廓、位置和空间关系，但允许更大幅度地重组内部比例、局部视角和色块节奏。不得变成不可辨认的纯抽象。

未明确指定强度时始终使用 `中等`，不要询问。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow。

脚本固定执行这些版式约束：

- 横版：原图在上、效果图在下；竖版或正方形：原图在左、效果图在右。
- 两图显示尺寸完全相同，原图不缩放、不裁切、不调色；效果图仅在宽高比通过校验后调整到原图尺寸。
- 背景 `#F7F4EE`；四周留白和两图间距均为单张图短边约 4%。
- 外沿描边 `#E5E0D7`，粗细为短边约 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、签名、Logo 或水印。

脚本允许效果图与原图的画幅比例相对偏差不超过 0.5%。超过上限时重新生成效果图；不得通过裁切、明显拉伸、压缩或加边伪装成匹配比例。

## 完成检查

交付前核对：输入 N 张、输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；默认风格为合成立体主义、中等抽象；主体仍可识别；方向布局正确；两图完整、等尺寸、无重叠；顺序与命名正确；所有成品均为高清 PNG。
