# 莫奈油画对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的莫奈效果图配对，最终输出数量必须与输入数量相同、顺序一致。不要把不同原图放进同一张画布，也不要向用户额外输出中间生成图。

## 执行流程

1. 按用户上传顺序记录全部原图的本地绝对路径。不要按文件名或文件系统顺序重排。若无法取得每张图的独立本地路径，在开始生成前说明阻塞；不要把多张参考图一起传给生成工具冒险处理。
2. 为每张原图建立独立临时目录。原始文件只读使用，不覆盖、不重命名、不转存为“原图替代品”。
3. 每次只处理一张原图，并调用图像生成工具一次：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不要同时传入其他原图。
   - 不要让生成工具制作拼图、边框、标题或对照版式；它只生成当前原图对应的莫奈油画效果图。
   - 使用下方“生成提示词”。
4. 检查效果图：画幅方向和比例与原图相同；构图、视角、主体位置、地平线、建筑、人物、自然景物、地标及主要几何结构均可对应辨认；没有新增、删除、移动或替换主要物体，也没有文字、签名、水印、Logo 或画框。
5. 若上述关键约束失败，针对观察到的偏差强化提示后重试当前图片，最多重试 2 次。不要用不合格结果拼版；达到上限仍失败时继续处理其余输入，并在最终回复中准确说明未完成项。
6. 使用 `scripts/compose_comparison.py` 将未经修改的原图像素与合格效果图确定性拼版。脚本会校验比例、依据原图方向选择布局，并输出 PNG；不要让图像模型生成原图区域。
7. 输出名优先使用 `<原文件名去扩展名>_monet_comparison.png`。发生同名冲突时在后者末尾添加上传序号，绝不覆盖前一张成品。
8. 完成一张后立即自动继续下一张，不要在批处理中途请求确认。全部完成后，只向用户呈现按上传顺序排列的最终对照 PNG。中间效果图和临时文件不得作为成品呈现；仅清理本次创建的临时目录。

## 生成提示词

对每张原图单独使用以下内容，并明确当前参考图是唯一内容依据：

> 将这张参考照片转化为克劳德·莫奈式的印象派手绘油画。严格保留参考照片的画幅比例、构图、视角、主体位置、地平线和主要几何结构；建筑、人物、自然景物与地标必须清晰可辨。不得增加、删除、移动、替换或重构主要物体，只改变媒介、色彩、光线质感和笔触。使用可见的断续笔触、柔和边缘、空气透视、明亮分色与自然画布肌理，营造莫奈式的光线感和空气感。阴影使用蓝绿、淡紫或冷灰，避免纯黑；依据原图自然采用赭石、陶土色、鼠尾草绿、翠绿、天蓝、淡紫、象牙白和浅金色。远景可融化为有节奏的色块和笔触，但主体结构必须准确。避免摄影滤镜、卡通、粗重描边、超现实变形、过度锐化、塑料质感和浑浊色彩。不得添加文字、签名、水印、Logo、画框或原图不存在的物体。输出只包含单张油画效果图，不要拼图，不要原图对照，不要留白边框。

如重试，只补充已经观察到的具体偏差，例如“人物位置向右漂移；请锁定在参考图相同坐标”，不要改写原图内容。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow。

脚本固定执行这些版式约束：

- 横版：原图在上、效果图在下；竖版或正方形：原图在左、效果图在右。
- 两图显示尺寸完全相同，原图不缩放、不裁切、不调色；效果图仅在宽高比通过严格校验后等比调整到原图尺寸。
- 背景 `#F7F4EE`；四周留白和两图间距均为单张图短边约 4%。
- 外沿描边 `#E5E0D7`，粗细为短边约 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、签名、Logo 或水印。

脚本允许效果图与原图的画幅比例相对偏差不超过 0.5%。超过上限时重新生成效果图；不得通过裁切、拉伸、压缩或加边伪装成匹配比例。

## 完成检查

交付前核对：输入 N 张、输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；方向布局正确；两图完整、等尺寸、无重叠；顺序与命名正确；所有成品均为高清 PNG。
