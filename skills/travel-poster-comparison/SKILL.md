# 旅行海报风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的旅行海报风效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能从“上半真实照片 + 下半印刷重构”的参考海报中提炼**印刷重构部分的视觉语言**，适配 `visual-style-skills` 的统一工作流：真实原图由确定性拼版脚本保留，图像模型只生成与原图同画幅的“档案式旅行海报效果图”。不要在效果图内部再次复制一张完整原图，也不要强制改成 3:4 或上下分栏。

用户提供的风格案例只用于提炼风格，不是运行时依赖；不得打包参考图，也不得要求用户重复上传。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录全部原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写“主体结构摘要”：
   - 主体类别与数量；
   - 主轮廓、方向、比例和关键透视；
   - 3–8 个不可丢失的建筑 / 地貌 / 景观识别点；
   - 周围环境中必须保留的关系；
   - 原图最具识别度的 1–3 个颜色。
4. 再写“印刷重构映射”：
   - 哪些区域保留为撕裂彩色照片碎片；
   - 哪些纹理转为黑色半色调点或影印颗粒；
   - 哪些边缘外溶为 ASCII 字符场；
   - 哪些几何结构用细技术线、圆弧、十字基准或刻度线提示；
   - 留白放在哪里，红色校准条放在哪里。
5. 使用风格指南中的生成提示词，只生成当前输入对应的一张效果图。效果图必须保持原画幅比例和裁切方向，不生成内部“原图 + 效果图”双栏。
6. 检查主体准确性：主体身份、比例、主轮廓、关键结构、朝向和主要透视必须一眼可辨；实验性纹理只能增强主体，不能遮挡或虚构重要结构。
7. 检查风格：暖灰 / 米白旧纸底；主体以撕裂照片、半色调、ASCII、细建筑线条共同重构；有纸纤维、褪色墨迹、轻微影印瑕疵与套印误差；保留部分原图柔和综合色；只有一个克制红色强调；负空间充足。
8. 以下情况视为失败并针对偏差重试，最多 2 次：主体被扭曲、拉伸或改造；关键结构被 ASCII / 半色调遮蔽；出现大量随机代码墙；虚构门窗、层数、结构件或技术规格；画面变成纯黑终端、赛博朋克、霓虹或故障艺术；综合色被完全去除；旧纸纹理过脏；元素过密、留白不足；出现品牌 Logo、二维码、水印、作者签名或旅游海报陈词滥调。达到上限仍失败时继续其余输入，并准确说明未完成项。
9. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
10. 输出名优先为 `<原文件名去扩展名>_travel_poster_comparison.png`。同名时添加上传序号，绝不覆盖已有成品。
11. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 题材适配

- 建筑 / 地标：优先保持立面、塔楼、圆顶、拱门、屋檐、窗带、结构曲线、体块比例和天际线；技术线用于辅助几何，不重新设计建筑。
- 自然地貌：保持山体、拱石、峡谷、海岸、树形或地平线的主轮廓；技术线可以抽象为地质测绘 / 档案研究语言，不伪造工程数据。
- 城市 / 街景：保留最有识别度的建筑群、道路、桥梁和空间走向；次要车辆、人群和杂讯可减少，但不能删除决定地点关系的关键对象。
- 室内 / 器物：若用户仍要求此风格，可把主体当作“档案标本”处理，保留结构与轮廓，减少建筑专用措辞，不强行添加不存在的城市或风景元素。

## 排版与文字

旅行海报语言可以包含少量固定宽度编辑文字，但文字不是风格成立的必要条件。默认优先保证视觉稳定：

- 用户提供准确的主体名称、城市 / 国家或文案时，可加入小型等宽标题、地点、`REC. STUDY 01` 和一句短观察。
- 用户没有提供准确名称时，不要凭空编造地点、技术数据或历史信息；可使用无文字版本，或只保留无语义的排版线、刻度和校准元素。
- 不生成品牌 Logo、二维码、水印、署名、假技术参数、假坐标或乱码文字。
- 文字必须小、轻、可读，不抢主体，不发展成商业旅游宣传标题。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体结构与身份准确可辨；效果图具有撕裂照片、半色调、ASCII、技术构造线、暖旧纸和单一红色强调；负空间充足，无代码墙、无赛博朋克、无虚构技术信息；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
