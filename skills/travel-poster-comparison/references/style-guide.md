# 旅行海报风风格指南

“旅行海报风”是一种把真实建筑、地标或自然景观重构为**建筑档案 × 模拟影印 × 早期数字字符系统 × 独立旅行编辑**的实验印刷图像。它的重点不是复古滤镜，而是让主体像从旧档案纸面中逐渐浮现：一部分仍是照片，一部分化成半色调、ASCII、技术线和纸纤维。

## 核心视觉语言

- **主体准确优先**：先保证结构身份、比例、透视和关键识别点，再做实验性处理。
- **照片碎片 + 印刷溶解**：主体核心区域可保留柔和综合色照片碎片，边缘逐渐分解为半色调、颗粒、ASCII 和线稿。
- **旧纸档案底**：米白、暖灰、浅褐纸张作为主背景，带轻微纤维、污渍和褪色，不做脏重古董纸。
- **早期数字感**：ASCII 只作为外围纹理和轮廓描摹，不作为建筑细节替代品。
- **技术绘图感**：细线、构造线、圆弧、基准十字、刻度和裁切标记提供“研究 / 档案”气质，但不伪装成真实工程图。
- **克制综合色**：保留主体的原始柔和综合色，并以黑墨和暖纸色统筹；只使用一个小面积红色校准强调。
- **负空间**：效果图通常让约 22%–38% 的纸面保持相对安静，避免数字屏幕式拥挤。

## 内容提炼

在生成前，先提取：

1. 主体是什么，有几个？
2. 主轮廓和整体倾斜 / 延展方向是什么？
3. 哪些立面、拱门、窗带、塔楼、圆顶、屋面、结构曲线或地貌轮廓一旦错误就会失去身份？
4. 周围景观、街道、草地、山体、天空中哪些关系必须保留？
5. 原图最有记忆点的 1–3 种颜色是什么？
6. 哪些低价值纹理可以被半色调和字符场替代？

不要先决定纹理，再把纹理强塞进主体；先锁定结构，再安排印刷分解。

## 主体重构层级

建议将效果图分为四类视觉层：

1. **核心照片层**：主体最重要、最具识别性的 30%–60% 区域，保留柔和综合色照片信息。
2. **撕裂拼贴层**：核心照片外围使用粗糙纸纤维边缘、局部缺口和撕裂形状，不做规则矩形蒙版。
3. **印刷分解层**：外围材质、阴影、天空、地面或次要环境逐渐变成黑色半色调点、影印颗粒和褪色墨。
4. **技术 / 数字层**：以极少 ASCII 字符场、细线、圆弧、基准线、十字与裁切标记组织空间。

层与层需要互相穿插，不要变成四块彼此割裂的效果贴纸。

## ASCII 使用规则

- 使用固定宽度字符形成稀疏矩阵、轮廓带或局部密度渐变。
- 字符可包括 `. : + - | / \\ = * # 0 1` 等简单字形，但不要形成大段可读代码。
- ASCII 只描摹外围综合色密度、影调或轮廓，不负责虚构窗户、门、拱券、岩层或结构零件。
- 单个字符场面积应受控，避免覆盖主体核心结构。
- 不使用终端黑底、绿色代码、霓虹蓝紫或 Matrix 风格。

## 半色调与影印

- 黑色 halftone dot 可以在天空、阴影、远景和主体边缘逐渐增密 / 变稀。
- 允许少量 photocopy noise、墨粉颗粒、斑点、漏印与褪色。
- 半色调应有清晰方向和层级，不要全图均匀铺点。
- 允许 1–2 处轻微套印误差，但不能做 RGB 故障分色。
- 主体综合色不能完全被黑白网点替代，除非用户明确要求综合色版。

## 技术构造线

- 使用极细黑灰线条：水平 / 垂直基准线、局部圆弧、切线、对齐十字、小刻度。
- 构造线可以穿过空白和拼贴边缘，但不要在主体表面形成密集网格。
- 不添加尺寸数字、材料参数、经纬度、工程编号等未经用户提供的“假规格”。
- 裁切角标、对齐标记和一条小红色校准条可以存在，但都要克制。

## 纸张与老化

- 背景优先：暖灰、奶油白、浅米黄、旧报纸浅褐。
- 纸纤维细腻、低对比；污渍少量、不规则、边缘柔和。
- 可有轻微折痕、褪色和印刷压痕感，但不要重度破损、烧焦、霉斑或“藏宝图”效果。
- 旧纸是安静底层，不能抢过主体。

## 色彩

- 主基底：暖灰旧纸 + 黑 / 深灰墨。
- 主体综合色：从原照片保留 1–3 个最重要综合色，如石材米白、砖红、玻璃蓝、草绿、沙岩橙、海水蓝等。
- 红色：仅用于一条小型校准条、一个注册点或极少量编辑强调。
- 禁止赛博朋克霓虹、高饱和综合色光效、综合色代码墙和综合色故障边。

## 构图

- 效果图沿用原始画幅比例，不强制 3:4。
- 主体通常占画面宽度约 60%–88%，根据最佳可读性决定；细高塔可更窄，横向建筑可更宽。
- 允许主体略微偏心，以留出标题区或档案空白，但不要为了版式扭曲建筑。
- 约 22%–38% 的区域应保持低信息密度，形成档案标本式留白。
- 不做模板化旅行宣传画，不使用大面积口号、徽章、贴纸或纪念品式装饰。

## 排版

若用户明确提供名称 / 地点 / 文案，可使用：

- 主标题：`[STRUCTURE NAME]`
- 次级：`[CITY, COUNTRY]`
- 记录行：`REC. STUDY 01`
- 一句短观察性说明。

使用小型、干净、可读的固定宽度或打字机感字体，置于留白区域。不要自动编造结构名称、城市、国家、日期、年份、参数或技术说明。若没有可靠文案，优先无文字，只保留构造线和校准元素。

## 与相近风格的边界

- **不是赛博朋克**：无黑底、霓虹、HUD、扫描线和高科技界面。
- **不是 ASCII 艺术主体**：主体不能主要靠字符堆成，字符只是外围介质。
- **不是复古旅游广告**：不用大号宣传口号、复古插画人物、徽章或明信片陈词滥调。
- **不是纯复印机效果**：仍需保留部分综合色和主体的照片信息。
- **不是建筑工程图**：技术线只是视觉语法，不宣称真实测绘数据。
- **不是破坏性拼贴**：撕裂和分解不能伤害主体结构辨识。
