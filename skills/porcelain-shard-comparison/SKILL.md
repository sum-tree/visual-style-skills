# 陶瓷碎片风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的陶瓷碎片风效果图配对，输出数量必须与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能只迁移“陶瓷碎片重构”的视觉语言，不继承来源案例中的上下双区海报、文字排版、壁纸尺寸或目录批处理规则。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按用户上传顺序记录全部原图的本地绝对路径。不要按文件名或文件系统顺序重排。无法取得独立路径时，说明阻塞；不要把多张原图同时作为同一次生成的内容来源。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用当前原图作为唯一内容依据，不同时传入其他原图或风格参考图。
   - 先识别主要主体的身份或类型、数量、姿态或方向、相对位置、遮挡关系、主轮廓与最重要的视觉记忆点。
   - 再决定碎片化方式：哪些轮廓由较大瓷片承担，哪些结构由小瓷片、间隙、缺口或裂纹表达；次要纹理可以简化，但主要主体不能消失或换成别的对象。
   - 从原图提取 2–5 个最有记忆点的颜色，并转译成相应釉色，不默认套用蓝白瓷。
   - 使用风格指南中的生成提示词。图像生成只负责当前效果图，不负责拼图、边框、标题、标签或原图区域。
4. 检查内容：主要主体的身份、数量、姿态或方向、总体位置、遮挡和关键空间关系仍可对应；允许删除无关微小纹理并用留白替代，但不得增加无关主体、改变主要物体类别、把人物或产品变成不可识别的碎片堆。
5. 检查风格：主体确由大小不一、边缘不规则的瓷器碎片重构；可见真实釉面、胎土断口、裂纹、缺角、碎片间空隙和轻微错位；颜色来自原图并呈釉色质感；传统纹样只作局部暗示；背景以温润瓷白或极浅中性色为主，并有明显留白和呼吸感。
6. 以下情况视为失败并针对偏差重试，最多 2 次：只是给照片叠加裂纹或陶瓷纹理；主体变成完整瓷器或雕塑；碎片过于规则、像马赛克或拼图块；默认全画面青花蓝；传统纹样堆满主体；画面被碎片填满、缺少留白；3D 塑料、树脂或金属质感；碎片没有真实断口与厚度；主要主体身份、数量、姿态或位置关系明显改变；出现文字、签名、水印、Logo、画框或装饰性版式。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先使用 `<原文件名去扩展名>_porcelain_shard_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- **人物与动物**：用较大的弧形或不规则瓷片承担头部、躯干和主要动作方向，用小片连接手足、毛发或衣褶记忆点；脸部不必照片级复刻，但人物身份、朝向与姿态必须可辨。
- **建筑、车辆与产品**：保留标志性外轮廓、关键开口、部件和方向；通过碎片边缘、缺口和少量纹样表现结构，不把对象改造成古董器皿。
- **风景与植物**：可把天空、水面、墙面等低信息区域转为大面积瓷白留白；山体、树冠、岸线或花朵用疏密不同的碎片群概括，但前中后关系仍需清楚。
- **复杂场景**：优先保留主叙事和最重要主体，合并重复纹理与杂讯；次要对象可弱化为低对比碎片，但不能删除会改变场景语义的重要主体。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体仍可辨；碎片具有真实釉面、胎土断口、裂纹、缺角、间隙和轻微错位；综合色来自原图而非固定青花蓝；有明显瓷白留白；无廉价国潮、马赛克、完整陶瓷器物、3D 塑料感和文字；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
