# 纸胶带拼贴风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的纸胶带拼贴效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能把“纯文本生成和纸胶带主题”的参考语言转换为适合 `visual-style-skills` 的照片风格化流程：真实原图由确定性拼版脚本保留，图像模型只根据当前照片生成与原图同画幅的和纸胶带拼贴效果图。不要强制改成 3:4，也不要在效果图内部再次复制真实照片。

用户提供的风格案例只用于提炼视觉规则，不是运行时依赖；不得打包参考图，也不得要求用户重复上传。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录全部原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写“识别摘要”：
   - 主体类别与数量；
   - 最关键的外轮廓、姿态、朝向与视觉重心；
   - 2–6 个不可丢失的结构或形状特征；
   - 原图最重要的前后关系、地平关系或叙事关系；
   - 3–6 个最具身份感的综合色。
4. 再写“胶带映射”：
   - 规划约 10–18 片主要胶带分别承担哪些轮廓、结构和大综合色；
   - 决定每片胶带的宽度、长度、方向、剪裁 / 手撕边、重叠关系和半透明叠综合色；
   - 选出必须保留的主体结构，删除低价值照片纹理和琐碎细节；
   - 确定主体在暖白纸面上的尺度、位置和最大留白区域；
   - 若存在水面、地面、阴影或倒影，只用少量横向 / 斜向胶带提示，不做写实纹理。
5. 使用风格指南中的生成提示词，只生成当前输入对应的一张效果图。效果图必须保持原画幅比例和裁切方向，不制作内部原图对照、上下分栏或海报边框。
6. 检查内容对应：主体身份 / 类型、数量、主轮廓、朝向、关键结构和主要空间关系仍可一眼对应。允许大幅概括与几何化，但不能把主体变成无关对象，也不能凭空加入与原图无关的地标、人物或装饰。
7. 检查胶带语言：画面主要对象必须真正由约 10–18 片和纸胶带构成，而不是普通扁平插画上叠纸纹。每片胶带应有可辨宽度、长度、方向与边缘；允许重叠、截断和局部穿插，但整体必须有清楚秩序。
8. 检查材质与配色：胶带具有轻微半透明、纸纤维、柔软纸张厚度、手撕边缘、极轻接触阴影与微小手工误差；配色来自原图并压缩为少量和谐综合色。背景为暖白、象牙白或自然微黄白纸，干净、低对比、无重度做旧。
9. 以下情况视为失败并针对偏差重试，最多 2 次：画面仍像照片或普通矢量插画；主体不是由明确胶带片构成；胶带片数量极多形成马赛克；复杂花纹过多；出现贴纸、邮票、票券、信封、胶带卷、剪刀、手、书桌或工艺工具；纸面严重泛黄、污渍或老化；出现重阴影、塑料 3D、油画、水彩、卡通渲染、剪贴簿杂乱；标题过大或乱码；出现品牌 Logo、水印或二维码。达到上限仍失败时继续其余输入，并准确说明未完成项。
10. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
11. 输出名优先为 `<原文件名去扩展名>_washi_tape_collage_comparison.png`。同名时添加上传序号，绝不覆盖已有成品。
12. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 题材适配

- 城市 / 建筑 / 地标：优先保留天际线、塔体、桥梁、屋顶、窗带节奏和最具辨识度的轮廓。高层建筑用竖向或斜向胶带分层，水面 / 地面用少量横向胶带提示。
- 人物：保留姿态、头身关系、服装大综合色和关键配饰，用较宽胶带建立躯干与服装，用较窄胶带提示四肢、发型或动作方向；不追求写实五官。
- 动物：保留物种、体型、姿态、耳尾 / 翅膀 / 角等识别点，用 10–18 片胶带组合成稳定剪影，避免卡通贴纸感。
- 植物 / 花卉：把花瓣、叶簇、枝条和生长方向转成不同宽度的胶带片；保持花型和节奏，不做碎片化马赛克。
- 器物 / 交通工具：保留功能轮廓、方向、主要零件与物体间关系，用胶带方向表达结构，不额外添加装饰性工艺用品。
- 自然景观：用少量胶带层表达山脊、水面、云层、海岸或树线，主体景观可辨即可，不填满整个画面。

## 文字规则

- 默认不自动生成文字，以保证稳定性。
- 若用户明确要求标题，可从可靠的主体 / 地点 / 主题中提炼 **1–3 个英文单词**，使用小型、精致、克制的编辑式排版。
- 标题必须明显次于拼贴主体，并放在自然留白区域；如果影响构图，宁可省略。
- 不生成长句、年份、坐标、品牌、邮戳、签名、说明段落或重复文字。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体可辨；效果图主要由约 10–18 片和纸胶带构成，具有半透明叠色、纸纤维、手撕边、轻微接触阴影、有限配色和大量暖白留白；无贴纸 / 邮票 / 工艺工具 / 剪贴簿杂乱 / 塑料 3D；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
