# 纸胶带拼贴风风格指南

“纸胶带拼贴风”是一种用**少量真实和纸胶带片**重新构成主体的高级平面拼贴语言。重点不是把照片贴上纸纹，也不是把对象切成无数碎块，而是让观者清楚看到：这个主题由约 10–18 片不同宽度、长度、方向和综合色的日本和纸胶带，通过撕、贴、叠、截和留白有意识地构成。

## 核心视觉语言

- **主题先行**：先锁定原图最能识别的主轮廓、结构、姿态和综合色记忆，再规划胶带。
- **10–18 片主要胶带**：控制片数，避免细碎马赛克；每片胶带都承担明确结构作用。
- **胶带即造型**：通过胶带方向、宽窄、截断、重叠和透明度共同塑造主体，而不是先画插画再加纸纹。
- **真实和纸质感**：半透明、纸纤维、柔软纸厚、自然撕边、极轻接触阴影、细微手工误差。
- **有限配色**：从原图提炼少量综合色，让重叠自然产生轻微综合色变化。
- **大面积留白**：主体像一件独立文具艺术品陈列在暖白日记纸上，不填满页面。
- **高级文具感**：干净、克制、当代、精致，接近日本文具品牌、独立设计杂志或小型画廊纸艺，而不是儿童手工。

## 与“剪纸拼贴风”的区别

- 剪纸拼贴强调**纸片色块、版画颗粒、民艺形状**；纸胶带拼贴强调**狭长带状材料本身的宽度、方向、半透明与叠贴关系**。
- 剪纸可以是任意形纸片；本风格的大多数构成元素必须仍能被识别为“胶带条 / 胶带片”。
- 本风格应更简洁、更文具化、更轻盈，尽量少用复杂肌理和印刷噪点。

## 识别与减法

生成前只保留真正决定识别度的信息：

1. 最外层轮廓；
2. 2–6 个关键结构；
3. 主体姿态 / 方向；
4. 最重要的前后关系；
5. 3–6 个综合色记忆点。

删除照片中的小窗、砖缝、叶纹、毛发、复杂反射、细小文字和随机背景杂讯。

## 胶带片语法

### 数量

- 目标：约 **10–18 片主要胶带**。
- 简单对象可 8–12 片；复杂建筑 / 城市可接近 18 片，但不要演变为几十个碎片。
- 不要用大量微小碎片补细节。

### 形状

- 以长条、短条、宽片、窄片、斜切片和局部撕裂片为主。
- 允许一端平切、一端手撕；也允许两端都自然撕裂。
- 可轻微裁成梯形、斜边或局部缺口，但仍应保有“胶带材料”的阅读感。

### 方向

- 竖向：塔楼、高层建筑、人体直立结构、树干。
- 横向：地面、水面、桥面、屋檐、地平线。
- 斜向：桥索、屋顶、肢体动作、山体坡面、动态结构。
- 弧形不靠真正弯曲胶带，而通过多片短胶带的方向变化暗示。

### 重叠

- 重叠区域允许自然加深或混色。
- 重叠面积应克制，避免厚重堆叠和脏综合色。
- 前后关系主要通过遮挡顺序和轻微接触阴影建立。

## 材质

正宗和纸胶带应具备：

- 轻微半透明；
- 可见但细腻的纸纤维；
- 柔软、不僵硬的纸张厚度；
- 手撕边缘和细微毛边；
- 胶带与纸面的极轻接触阴影；
- 少量自然起伏或粘贴误差；
- 综合色平涂或非常低调的基础图案。

禁止：

- 塑料胶带、亮面胶带、PVC 反光；
- 厚重立体投影；
- 复杂花纹、贴纸图案、文字胶带；
- 大量褶皱、翘边或故意做旧。

## 配色

- 从原图中选择 **3–6 个核心综合色**，并做综合色统一和适度降饱和。
- 可使用蓝灰、雾蓝、赭石、灰绿、砖红、米黄、青灰等高级文具综合色。
- 允许综合色重叠产生柔和第四色 / 第五色，但不要制造霓虹或高饱和综合色。
- 主体的标志性色必须优先保留，例如东方明珠的红、自由女神的铜绿、海水的蓝等。
- 避免综合色过灰、过糖果、过复古发黄。

## 背景与留白

- 使用暖白、象牙白或自然微黄白纸。
- 纸纹极度轻微，低对比，只在近看时可见。
- 主体通常占画面约 45%–72%，根据原图复杂度调整。
- 至少保留一块连续大留白区域。
- 不加入书桌、手、剪刀、胶带卷、票券、邮票、信封或其他工艺情境。

## 题材映射

### 城市 / 地标

- 用竖向胶带建立塔楼、高层与轮廓节奏。
- 关键桥梁可用横向 + 斜向窄胶带表达桥面和桥索。
- 远景只保留低对比胶带群，不逐栋细画。
- 水面倒影用 3–6 片短横胶带提示即可。

### 人物

- 躯干和服装用 2–5 片宽胶带；四肢、发型、配饰用窄胶带。
- 重点是姿态和综合色，不做真实五官。

### 动物

- 先建立整体剪影，再用少量胶带强调耳、尾、翅、角、斑纹。
- 不做卡通眼睛和贴纸轮廓。

### 植物

- 枝干使用窄长胶带；叶片 / 花瓣用短片和交叠。
- 保留生长方向，不堆满叶片碎块。

### 器物 / 交通工具

- 以功能轮廓和关键零件为准，优先用方向清晰的胶带片表达结构。
- 不加入桌面道具来解释“手工制作”。

## 标题

参考案例允许一个很小的地点 / 主题标题，但标题不是风格成立的必要条件。

- 默认无文字。
- 用户明确要求时，标题限 1–3 个英文单词。
- 使用小型、精致、简约、字距略松的编辑字体。
- 放在自然留白处，明显次于主体。
- 若标题破坏平衡则省略。

## 明确避免

- 普通贴纸拼贴；
- 剪贴簿 / scrapbook 杂乱；
- 邮票、票券、卡片、信封；
- 胶带卷、剪刀、手、桌面、工具；
- 复杂花纹胶带；
- 油画、水彩、彩铅、粗糙蜡笔；
- 塑料 3D、玩具质感、厚重投影；
- 逼真照片对象直接叠在纸上；
- 脏背景、重做旧、重复纸纹。
