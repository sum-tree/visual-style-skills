# 传统意象水彩风格指南

这里的“传统意象水彩”也覆盖用户口中的“传统意向水彩”：以传统透明水彩的水、色、纸关系表现对象，不追求逐像素复制，而是提炼主体结构、色彩气氛和视觉节奏。参考画中的树只是范例，任何题材都应使用同一种形式逻辑重新组织，不能强行添加树木。

## 三张参考归纳

- **结构骨架**：细而深的树干与枝条承担明确结构，数量不多但位置准确；它们与周围松散色团形成清晰的硬软边对比。
- **透明色团**：树冠不是逐叶描画，而由湿画法晕染、叠色、返花、沉淀和边缘水痕组成。色团有疏密和大小节奏，局部重色只用于聚焦。
- **主动留白**：纸白不是未完成区域，而是空气、光和距离。主体常被大片白纸包围，地面只用低矮薄洗轻轻锚定。
- **不对称平衡**：主体成组但不机械居中；色彩重心、枝干节奏和空白面积相互制衡。小幅远景可像纸上浮起的水彩札记，近景则允许色团占据更大面积。
- **明亮配色**：常见橙、珊瑚红、玫瑰、粉、金黄、黄绿、鼠尾草绿、蓝绿和天蓝。通常从 4–7 色中建立一组主色、邻近色与少量冷暖对照，保留纸白调和，避免全色域堆叠。
- **受控偶然**：飞溅、滴点、色素聚集和不规则水边围绕主体节奏出现；它们补充空气感，不能替代构图或遮住关键结构。

## 造型层级

先把当前照片分为三层：

1. **结构锚点**：选择 1–3 类必须准确的线、轮廓或局部，例如人物面部与姿态、动物头身轮廓、建筑主透视、车辆外形、树干、山脊或岸线。用湿画干画的细深线、清楚硬边或小面积重色表达。
2. **可松化色块**：衣物、树冠、花叶、云、水面、墙面或背景人群等可合并为透明湿画色团，保留总体位置和色彩关系，不逐项描写纹理。
3. **纸白与失边**：次要背景、空气、光区和远景允许溶入纸白。失边必须服务于空间和聚焦，不能把主体身份一并消除。

主体数量、身份、主要姿态、总体位置、关键轮廓和前中远顺序必须保留；小纹理、次要边界和背景细节允许诗意概括。构图可以更疏朗，但不得把原图改成另一处场景。

## 生成前场景摘要

每张图都先生成一份仅供本次提示词使用的内容清单，至少包括：

- 主要物体、人物和动物分别是什么，各有多少；人物或动物的身份特征、姿态、朝向和主要服饰或花纹。
- 各主体位于左、中、右及上、中、下的哪一带，谁遮挡谁，彼此距离和大小关系如何。
- 前景、中景、远景分别有哪些关键对象；地平线、道路、岸线、建筑透视或主要运动方向在哪里。
- 每个主体赖以识别的 1–3 个特征，以及绝对不能删除、替换或合并的对象。
- 哪些细节可以松化成色团，哪些线、轮廓或局部必须成为结构锚点。

摘要必须具体，例如“右下前景一名侧身站立、面向左侧的人物；左后方两棵相互重叠的树；远景低矮建筑沿地平线横向排列”，不能只写“有人和树”。

## 参考图配色映射

三张参考的共同用色不是固定色卡，而是一套关系：暖色形成主要发光色团，冷色在下方、侧方或阴影处稳定画面，深色细线负责结构，未着色纸白贯穿并把颜色调亮。

1. 从参考色域中选 4–7 色：暖橙、珊瑚红、玫瑰粉、金黄、柠檬黄、黄绿、鼠尾草绿、蓝绿、群青或天蓝。
2. 指定一个占主导的暖色族或黄绿色族，用于最重要主体或视觉焦点；再用 1–2 个邻近色制造湿润层次。
3. 用面积更小、饱和度较低的蓝绿、天蓝、鼠尾草绿或淡紫灰平衡主色，常用于阴影、远景、下部承托或次要对象。
4. 结构线限定为深靛蓝、佩恩灰或焦褐，避免纯黑；它们只落在场景摘要确定的结构锚点上。
5. 保留充分纸白穿过色团，形成高光、空气和对象之间的呼吸；亮色不得铺满画布。
6. 原图本身的重要颜色身份仍要可理解。例如黑白猫不能变成橙色猫、红色车辆不能失去红色识别，但可把固有色转译成符合上述冷暖关系的透明水彩层次。

配色计划应写明“主色团、辅助邻近色、冷色平衡、结构线颜色、主要留白位置”，而不是只列颜料名称。

## 水彩材料语言

- 使用透明叠染、湿画湿、湿画干、色素沉淀、颗粒感、回流水痕、返花、提亮、干笔擦痕和少量飞溅。
- 让纸张纹理从薄色和留白中自然显现；高光来自纸白或提色，不来自塑料感白色涂料。
- 清晰结构线采用深靛蓝、佩恩灰、焦褐或综合色，不用纯黑粗描边；线条应有粗细、断续和浓淡变化。
- 色团边缘同时包含柔软渗化、局部硬边和自然失边。不要把所有区域处理成同一模糊度。
- 以 4–7 种明亮透明颜料为主。根据原图自然选用暖橙、珊瑚红、玫瑰、金黄、黄绿、鼠尾草绿、蓝绿、群青或天蓝，并控制互补色混合以防浑浊。
- 地面或承托面只需一条低位薄洗、浅影或淡倒影来锚定主体；除非识别场景所必需，不完整描绘背景。

## 与合集其他风格的边界

- **不是莫奈油画**：没有不透明厚涂、碎笔覆盖、油彩高光或画布堆积；颜色依靠水与纸的透明叠加。
- **不是中国山水水墨**：不使用墨分五色、皴擦点染、散点透视或传统山水程式重造空间；纸白来自水彩留白而非水墨云烟体系。
- **不是现代工笔写生**：不要求每个物体都用细线准确勾勒，不追求道路、建筑和纹理的全面高保真；只让关键结构清楚，次要部分主动松化。
- **不是数字插画**：没有均匀矢量色块、空气笔渐变、发光边缘、霓虹色、塑料表面或一键滤镜感。

## 生成提示词

对当前原图单独使用，并把生成前完成的“场景摘要”“配色计划”和“结构锚点”填入相应位置：

> 将这张参考照片转化为传统意象透明水彩画。参考照片是唯一内容依据。场景摘要：〔具体列出主要物体、人物与动物的数量、身份或类型、姿态或朝向、位置、遮挡、前中远关系和关键识别特征〕。保持原画幅比例和裁切范围，逐项保留摘要中的主体数量、身份、主要姿态或总体轮廓、关键识别特征、总体位置以及前中远空间顺序；不得换主体、改变场景语义或随机增删物体。允许简化小纹理、合并次要背景，并让不重要的远景边缘溶入纸白。结构锚点：〔列出 1–3 类必须准确的线、轮廓或局部关系〕。配色计划：〔写明主色团、辅助邻近色、冷色平衡、结构线颜色和主要留白位置〕。仿照参考画的用色关系，以暖色或黄绿色透明色团形成焦点，以较小面积的蓝绿、天蓝、鼠尾草绿或淡紫灰稳定阴影与远景，以深靛蓝、佩恩灰或焦褐立骨，并让纸白穿过各色团；同时保留原图重要对象的固有色身份。先用纤细水彩线、断续线和少量清楚硬边建立结构锚点，不要给所有细节描边。再从暖橙、珊瑚红、玫瑰粉、金黄、柠檬黄、黄绿、鼠尾草绿、蓝绿、群青和天蓝中选择 4–7 种明亮透明颜色，以湿画湿色团、薄层叠染和局部湿画干笔触组织次要形体。保留大面积自然纸白作为空气与光，让色团出现柔软渗化、失边、返花、回流水痕、颗粒沉淀、提亮、少量干笔和克制飞溅；局部重色只用于焦点。色团要有疏密、大小与冷暖节奏，清晰结构与松散色块形成鲜明但自然的硬软边层级。用低位薄洗、浅影或淡倒影轻轻锚定主体，不把背景整面涂满。整体应轻盈、透明、疏朗、明亮，像在优质白色水彩纸上以观察和取舍完成的传统写意式透明水彩，而不是把原照片套上滤镜。不要照搬树木题材，不得强行增加树木、花朵或飞鸟。避免不透明水粉和丙烯、厚重油画、莫奈碎笔、中国水墨与皴法、全面工笔勾线、照片级渲染、数字喷枪、均匀矢量色块、动漫、霓虹、塑料质感和浑浊颜色。不得添加文字、题款、印章、签名、水印、Logo、画框或原图中不存在的物体。输出只包含单张效果图并填满原始画幅，不要制作原图对照或装饰边框。

重试时只补充观察到的偏差。例如：“当前背景被完整涂满且色层不透明；恢复大面积纸白，把次要背景溶解为透明湿画色团，仅保留人物面部、姿态和衣服大轮廓为结构锚点。”
