# 传统意象水彩对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的传统意象水彩效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能保存的是一种以“结构少而准、色彩松而透、水流清楚可见、纸白主动参与构图”为核心的透明水彩语言。水彩技法本身优先于物体表面的逐项描摹：预湿后的颜料应自然晕染、流淌、融合并在水边沉淀，形成橙、黄、绿、粉相接的高饱和彩虹色块和梦幻情绪。它不复刻参考图中的树木题材，而是把当前照片的主体翻译为少量结构骨架、大片湿画色团和留白之间的关系。它不同于莫奈式不透明碎笔油画、中国山水的墨法与造境，也不同于现代工笔写生对所有细节的高保真勾勒。

用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制、打包或要求用户重新上传该参考。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。无法取得独立路径时，在生成前说明阻塞；不要把多张原图一起交给图像生成工具。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 先写一份当前图的简短“场景摘要”：列出主要物体、人物和动物的数量、身份或类型、姿态或朝向、画面位置、相互遮挡与前中远关系，以及必须保留的关键识别特征。不可只写“风景”“人物”等笼统类别。
   - 再写一份“湿画配色计划”：默认以高饱和透明橙、金黄、黄绿、翠绿、珊瑚粉和玫瑰粉组成连续彩虹湿染，并以少量蓝绿或淡紫灰平衡；说明哪些大片区域应先预湿、颜色从哪里流向哪里、哪里保留沉淀水边和纸白。深靛蓝或焦褐只用于少量结构线。保留原图重要对象的固有色身份，不得机械照抄与当前内容无关的颜色位置。
   - 使用风格指南中的生成提示词，并依据场景摘要判断 1–3 个结构锚点、可松化的次要色块和应保留的纸白区域。将场景摘要与配色计划一并写入生成提示词。
   - 图像生成只负责当前效果图，不负责拼图、边框、标题或原图区域。
4. 检查内容：画幅方向与比例、主体身份与数量、总体位置、主要姿态或轮廓、前中远空间顺序和关键识别特征均可对应。允许简化小纹理、弱化背景和让次要边缘溶入纸白，但不得换主体、改变场景语义或随机增删物体。
5. 检查风格：纸白大面积可见；至少有数个连贯的大型湿画色域，而不是由许多干碎小笔触拼成；橙、黄、绿、粉在湿漉状态下形成清楚的彩虹渐变、自然晕染与失边，并可见重力流淌、边缘积色、颗粒沉淀、返花或回流水痕；色彩饱和但透明发光、不浑浊；少量清晰结构线与松散写意色块形成层级；画面具有梦幻、情感化而非写实说明式的气氛。
6. 以下情况视为失败并针对偏差重试，最多 2 次：没有依据场景摘要保住主要物体或人物；结果只是照片滤镜；画面被均匀填满；使用大量干燥、短碎、重复点触或多边形马赛克纹理逐项描摹物体；缺少明显的湿染融合、流淌和沉淀；橙黄绿粉彼此孤立、低饱和或混成脏灰；水彩不透明、厚重或塑料化；所有边缘同样清晰或同样模糊；飞溅无结构地覆盖主体；主体身份、数量、姿态或大轮廓丢失；结果像莫奈油画、中国水墨、现代工笔、丙烯、卡通或数字喷枪；出现文字、题款、印章、签名、水印、Logo、画框或新物体。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先为 `<原文件名去扩展名>_traditional_watercolor_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- 树木、花草与自然场景：以树干、枝条、山脊、岸线等少量深色线或清楚边缘立骨，树冠、花叶、天空和倒影转化为相互渗化的透明色团。
- 建筑、街道、车辆与产品：保留可识别外轮廓、透视和关键部件，只选择少量结构线清楚表达；次要材质和背景可用薄洗、失边和纸白概括，不古装化或更换功能。
- 人物与动物：保持数量、身份特征、姿态、朝向和主要花纹；面部、肢体或轮廓作为结构锚点，衣物、毛发和环境以透明色层松化，但不能失去身份。
- 复杂场景：优先保留主要对象之间的空间关系和视觉节奏，将琐碎背景合并为少量透明色域；不要把“简化”误用为删除关键对象。
- 高调或极简照片：扩大纸白并减少色数；低调或色彩丰富照片：仍须保留透光感和纸白通道，不能把整幅画成厚重暗色。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、印章、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；场景摘要覆盖主要物体、人物或动物及其空间关系，效果图逐项可辨；效果以橙黄绿粉的高饱和透明彩虹湿染为主，具有自然晕染、流淌、沉淀、失边、纸白和少量线骨，不呈现干碎马赛克式描摹；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
