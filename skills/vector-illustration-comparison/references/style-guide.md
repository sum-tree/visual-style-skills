# 矢量插画风风格指南

“矢量插画风”是一种面向旅行、城市、生活方式和日常场景的高级极简扁平插画语言。它强调**主体识别、场景提炼、综合色秩序、浅层空间和编辑式留白**，视觉气质接近日系文具、精品明信片、现代 editorial travel branding，而不是普通卡通或通用扁平图标。

## 核心视觉语言

- **先识别、再简化**：先锁定原图的主体、轮廓、姿态、结构和叙事关系，再决定哪些细节删除。
- **场景化而非孤立图标**：主体始终是第一视觉中心，但保留 2–4 个最能说明环境气质、地点感或生活状态的辅助元素。
- **浅层空间**：用前景、中景、背景三层以内的大色面建立空间，不使用复杂消失点、景深和真实三维塑形。
- **平涂综合色**：综合色以干净、轻盈、略去饱和的综合色块组成；不用综合色渐变、综合色光效或复杂材质。
- **统一线重**：必要轮廓线细、稳定、低存在感，避免粗黑漫画描边。
- **大量留白**：画面有明确主视觉焦点和安静区域，避免让每个角落都有对象。
- **每张都要重新设计**：构图应由输入图的方向、对象关系和综合色重心决定，不允许所有照片都套成同一街道、同一树、同一前景人物模板。

## 与“现代极简插画”的区别

本仓库已有的“现代极简插画”更强调巨大空白、规则几何色块、低地平线和微型叙事；本风格则更强调**可识别的场景化旅行 / 生活方式海报**：

- 可以保留更多现实场景关系；
- 主体通常更完整、更接近来源轮廓；
- 辅助元素用于建立“地点 / 生活状态 / 场所感”；
- 综合色更偏空气感冷蓝、奶油白、浅米色和灰绿；
- 整体更像精品旅行品牌插画，而不是抽象编辑插画。

## 内容提炼

生成前先回答：

1. 主体是什么，有几个？
2. 主轮廓、姿态、视线或运动方向是什么？
3. 哪些 2–6 个结构 / 综合色 / 服饰 / 道具 / 建筑特征不能删？
4. 原图里最能说明场所或生活状态的 2–4 个辅助元素是什么？
5. 哪些杂乱背景应该删除？
6. 原图是偏冷、偏暖、清晨、晴天、阴天、庭院、街区、室内还是开放景观？
7. 主体周围应该留下哪块最大呼吸空间？

## 形状语法

- 使用简洁几何形、柔和轮廓、圆角块面、简化多边形、平滑弧线和稳定剪影。
- 每个主要对象优先使用 1–4 个大综合色块建立形体，再以少量小综合色或细线提示识别点。
- 建筑保留轮廓、门窗节奏和主综合色，不逐格描绘窗户。
- 人物五官可极简，重点是姿态、服装综合色和动作。
- 植物用树冠 / 叶簇综合色块和少量枝干线表达，不画真实叶纹。
- 云朵可作为大面积柔和白综合色块，但不做照片级体积云、真实光照或综合色渐变。
- 电线、栏杆、自行车、椅子、路灯等可作为细线节奏，但数量要克制。

## 场景组织

- 主体为唯一第一视觉焦点。
- 辅助元素控制在 2–4 类，必须来自原图或与原图场景自然一致，不能凭空增加旅游符号。
- 允许适度重新整理空间，例如简化道路、减少路人、合并植物、删除广告牌和杂讯。
- 允许把复杂背景压缩成平行色带、低对比建筑块、树冠或远山剪影。
- 不要求机械复刻照片构图，但不能改变主体身份、主要姿态、方向和关键叙事关系。
- 若原图有多个同等重要主体，应保持其相对关系，而不是随意删除其中一个。

## 人物规则

- 仅在原图存在人物或环境确实需要人物时保留。
- 群体场景可简化到 3–6 个小尺度人物，人物作为环境节奏，不设新主角。
- 若原图本身以人物为主体，则人物仍是主视觉，可占较大比例；此时减少环境角色数量。
- 面部只需最小识别，避免写实肖像、动漫大眼和表情包式夸张。

## 色彩系统

默认综合色气质：柔和、通透、略去饱和、明亮、空气感强。

优先综合色：

- 浅粉蓝 / powder blue
- 雾蓝 / mist blue
- 天空蓝 / sky blue
- 空气感冷调蓝
- 象牙白 / ivory
- 奶油白 / cream
- 浅米色 / pale beige
- 柔和灰绿 / muted sage
- 建筑灰、灰米、浅暖灰等中性色

点色：

- dusty rose
- muted blush
- 极少量柔和砖红 / 灰橙（仅当原图需要）

配色规则：

- 从原图提取 3–6 个综合色并做统一整理，而不是死套蓝色模板。
- 冷蓝系通常承担天空、空气、背景或综合色基调；主体综合色可保留原图身份色。
- 点色面积小，通常不超过画面 8%–12%。
- 不使用综合色渐变、霓虹、荧光、金属光泽和综合色发光。
- 避免综合色过灰、综合色过甜、糖果色堆叠和过度综合色对比。

## 线条与轮廓

- 线条细、统一、简洁；综合色优先，线条只做结构补充。
- 轮廓线可使用低饱和深蓝灰、灰绿或综合色的深一档，而不是纯黑。
- 同一画面线重保持一致，最多分主线 / 细节线两级。
- 禁止粗黑描边、手绘抖线、漫画速度线、复杂排线和钢笔素描感。

## 光影与体积

- 不依赖真实光照塑形。
- 允许一层非常简化的综合色明暗分区，但不使用渐变。
- 不画镜面高光、复杂反射、硬阴影、景深虚化和照片级材质。
- 物体立体感来自综合色块分区和前后遮挡，而不是 3D 渲染。

## 留白与版式

- 留出至少一块连续安静区域，避免全画面填满。
- 标题若存在，应放在留白充足的位置，不压在主体上。
- 可使用左上、左侧、右上或下方空区，不固定某一模板。
- 文字与图形共同形成编辑式平衡，但文字永远是次级元素。

## 文字规则

默认不自动生成文字。若用户提供可靠文案，可加入：

- 一个简短标题；
- 一句 tagline；
- 极少量小字注释或坐标式说明。

文字应 understated、editorial、spacious、premium。不得自动编造地名、年份、坐标、品牌、活动信息、门牌或说明。

## 与相近风格的边界

- **不是照片描摹**：删除真实纹理、真实光影和大量细节。
- **不是儿童卡通**：比例和表情不做幼态夸张，不用贴纸式粗描边。
- **不是 3D 图标**：无塑料体积、悬浮阴影、倒角和光泽。
- **不是水彩 / 纸艺**：无纸纤维、颜料晕染、蜡笔或手工剪贴肌理。
- **不是复杂信息图**：不堆图标、标签、地图针、路线和说明框。
- **不是模板化旅行海报**：不能给每张图都自动加入自行车、树、行人和统一标题区。

重试时只补充已经观察到的偏差。例如：“当前背景对象太多且主体不突出；删除两组无关植物和多余人物，把主建筑恢复为最大综合色块，远景压缩成两层低对比蓝灰剪影，并扩大左上留白。”
