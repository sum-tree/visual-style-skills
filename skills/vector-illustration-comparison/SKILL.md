# 矢量插画风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的矢量插画效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能从“真实照片 + 下方扁平旅行插画”的参考海报中提炼**矢量插画部分的视觉语言**，适配 `visual-style-skills` 的统一工作流：真实原图由确定性拼版脚本保留，图像模型只生成与原图同画幅的场景化矢量插画效果图。不要在效果图内部再次复制真实照片，也不要强制改成 3:4 或上下分栏。

用户提供的风格案例只用于提炼风格，不是运行时依赖；不得打包参考图，也不得要求用户重复上传。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录全部原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写“识别摘要”：
   - 主体类别与数量；
   - 主轮廓、姿态、朝向和视觉重心；
   - 2–6 个不可丢失的结构、服饰、色彩或环境识别点；
   - 原图中最重要的前后关系与叙事关系；
   - 原图的综合色温和 2–4 个值得保留的综合色。
4. 再写“矢量场景映射”：
   - 指定唯一主视觉焦点；
   - 选择 2–4 个真正有助于说明地点、对象、生活状态或环境气质的辅助元素；
   - 决定哪些内容转为大平涂块、哪些用简洁轮廓线、哪些细节删除；
   - 规划前景、中景、背景的浅层分组与主要留白位置；
   - 若需要人物，只保留少量小尺度人物作为环境节奏，不制造新的主角。
5. 使用风格指南中的生成提示词，只生成当前输入对应的一张效果图。效果图必须保持原画幅比例和裁切方向，不生成内部“原图 + 插画”双栏。
6. 检查内容对应：主体身份、数量、姿态、朝向、关键结构和主要叙事关系仍可一眼对应；允许重新整理场景层次、删除杂讯和简化透视，但不得更换主体或凭空添加与原图无关的地标、交通工具、植物或装饰。
7. 检查风格：画面必须明显是高级极简扁平矢量插画；综合色柔和、通透、略去饱和；优先以浅粉蓝、雾蓝、天空蓝、空气感冷调蓝建立主氛围，并以象牙白、奶油白、浅米色、灰绿和建筑中性色平衡；仅允许很小面积 dusty rose / muted blush 点色。
8. 以下情况视为失败并针对偏差重试，最多 2 次：画面仍像照片；出现写实光影、复杂体积、渐变、纸纹、水彩或笔刷肌理；综合色过饱和、过暖或杂乱；轮廓线粗细混乱；场景被过多道具填满；出现多个同等焦点；所有输入都被套成相同街道 / 前景 / 植物模板；添加与原图无关的地标；人物过大成为主角；出现 3D、卡通贴纸、游戏 UI、品牌 Logo、水印或乱码文字。达到上限仍失败时继续其余输入，并准确说明未完成项。
9. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
10. 输出名优先为 `<原文件名去扩展名>_vector_illustration_comparison.png`。同名时添加上传序号，绝不覆盖已有成品。
11. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 题材适配

- 城市 / 街景：保留街区层次、屋顶线、道路、线缆、地标建筑与最具地方感的结构；可用少量自行车、行人、树木或标牌建立生活感，但不得堆砌“旅游符号”。
- 建筑 / 地标：保持建筑主轮廓、比例、朝向、开口与标志性结构，用 3–6 个大色面概括体块，弱化真实玻璃反射和阴影。
- 人物 / 日常生活：保留人物姿态、服装综合色、动作和与道具的关系；人物五官极简化，用综合色和剪影保证身份感，不画写实肖像。
- 动物：保留物种、姿态、体型和主要花纹，用平面色块和克制轮廓表现，不做毛发写实。
- 植物 / 花卉：保留叶冠、枝条方向、花型和分布节奏，以简洁叶片块和综合色簇表示，不画纹理细节。
- 器物 / 食物 / 交通工具：保留功能轮廓、摆放方向、关键零件和物体间关系；允许适度几何化，但不能变成错误品类。
- 自然景观：保留天空、云层、山体、水面、海岸或树线的主形与层次，用柔和大色面构成环境，不增加与地点无关的建筑和人物。

## 文字与编辑排版

矢量旅行 / 生活方式海报可以包含少量文字，但默认输出以稳定的无文字效果图为主：

- 用户明确提供可靠的地点、对象名称、主题词或文案时，可加入一个简短标题和一句克制 tagline，并放在留白充足的位置。
- 可加入极少量小字、坐标式注释或微型说明，但不得伪造地名、年份、坐标、品牌或活动信息。
- 文字必须小、轻、宽松、编辑感强，不形成商业大标题栏，也不能压过主体。
- 用户未提供可靠文字时，默认无文字，避免乱码、错字和模板化排版。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体身份、姿态和叙事关系可辨；插画具有平涂色块、统一线重、浅层场景、柔和蓝系综合色、克制辅助元素和充足留白；无真实光影、无渐变、无纸纹、无 3D、无模板化复制；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
