# 剪纸拼贴风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的剪纸拼贴效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能提炼的是一种“新民艺剪纸拼贴 + 版画印刷 + 编辑式留白”的纯风格语言，不复刻示例海报里的固定标题、日期、编号或上下分栏结构。用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制、打包或要求用户重新上传参考图。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
2. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 先写“识别摘要”：列出主要主体数量、类别、姿态与方向、相对位置、遮挡关系、空间顺序，以及最不能丢失的 2–6 个识别结构。
   - 再写“拼贴映射”：确定哪些部分用大剪影、哪些部分用分层色纸、哪些部分只保留刻线或负形，决定保留哪些辅助元素、删除哪些细碎纹理。
3. 使用风格指南中的生成提示词，只生成当前图片对应的单张效果图。图像生成只负责当前效果图，不负责制作原图区域、海报分栏、边框、标题、编号或说明文字。
4. 检查内容保持：主体数量、身份、方向、主要轮廓、关键姿态和相互叙事关系均可对应。允许压扁透视、删去重复纹理和次要背景，但不能更换主体、杜撰无关物件，也不能把关键主体缩成不可识别的小块。
5. 检查风格：背景为米白、暖白或浅纸色；画面有明显留白；对象以独立彩纸块、剪影、色面、刻线和少量层叠重构；边缘略带手工剪切感；可有轻微套印偏差、掉墨感、温和颗粒与纸张纤维；综合色由原图提炼后的 2–4 色主导，明快但克制。
6. 以下情况视为失败并针对偏差重试，最多 2 次：主体识别关系丢失；画面仍保留照片级细节；没有明显纸艺 / 拼贴感；配色灰脏或杂乱；颜色过多；边缘过于光滑矢量；出现真实三维光影、复杂透视、3D 渲染、照片滤镜或卡通贴纸感；背景被填满、留白不足；擅自加入模板化标题、签名、印章、Logo、水印、编号或说明文字。达到上限仍失败时继续处理其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先为 `<原文件名去扩展名>_paper_cut_collage_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- 风景 / 建筑 / 城市：保留天际线、楼体节奏、山形、水岸、树带或地平关系，把复杂细节压缩成 2–6 个主要剪纸块和少量辅助形。
- 食物 / 静物：保留器皿轮廓、食物层次、装饰位置和食材识别点，用简洁色块重构体块关系，避免写实高光和质感堆砌。
- 人物 / 动物：保留姿态、头身比例、面部朝向、花纹或服饰大轮廓；细节靠剪影、内轮廓线和少量色块提示，不做写实五官与体积塑形。
- 植物 / 花卉：保留花型、叶序、枝条方向和盛开姿态，以彩纸片状结构和刻线概括，不复制繁复纹理。
- 器物 / 交通工具：保持功能轮廓、方向和关键部件关系，用几何块面和拼贴层级表现，不得因极简化而更换品类或结构逻辑。
- 已经很简洁的原图：减少色数与细节，不额外增添装饰。复杂原图：保主叙事、删次要纹理，但不删关键主体。

## 文字与版式

默认输出保持品牌中立、无文字。参考图中的小标题、英文副标题、年份、编号、印章和说明字样只作为“编辑式留白与排版气质”的案例线索，不属于本技能的默认输出内容。只有用户明确要求并提供可用文案时，才可额外处理文字排版。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；效果图能一眼识别与原图的主体对应关系，并具有明确的剪纸拼贴、版画颗粒、纸面留白与克制配色；无写实透视、无 3D、无自动模板文字；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
