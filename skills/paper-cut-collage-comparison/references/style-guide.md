# 剪纸拼贴风风格指南

“剪纸拼贴风”是一种把真实对象重新压缩为纸艺色块、剪影、刻线与留白的平面语言。它既不是儿童手工课式的随意剪贴，也不是光滑矢量图标，而是带有新民艺气息、版画肌理和独立出版物版式意识的当代纸本拼贴图像。

## 视觉核心

- **主体提炼优先**：先抓住原图最能让人认出的轮廓、姿态、结构和叙事关系，再决定如何简化。
- **纸片重组**：主体、植物、建筑、器物或环境元素都像一块块独立彩纸重新拼成，不直接照搬照片明暗。
- **平面化重构**：用剪影、几何块面、正负形、少量刻线和局部层叠重构对象，不追求写实透视和体积。
- **留白参与构图**：纸白不是空背景，而是节奏、呼吸、停顿和主次关系的重要组成部分。
- **现代民艺感**：允许适度稚拙、符号化和几何化，但要克制、清爽、有设计秩序，不廉价、不幼稚。
- **印刷与纸张质感**：轻微套印偏差、掉墨、颗粒、纸纤维、边缘毛感和艺术纸底纹可以存在，但只是辅助，不可喧宾夺主。

## 造型语言

- 主体用 **2–8 个主要纸块** 建立大形；复杂主体可更多，但仍应层级清楚。
- 优先使用剪影、半抽象几何块、圆角形、梯形、三角形、弧形、简化叶片形和不规则纸片轮廓。
- 内部结构尽量靠色块交叠、开槽、刻线、压印感或少量孔洞表现，而不是写实描边。
- 可保留少量辅助元素，如一片云、一枝叶、一两颗果实、几粒咖啡豆、一段台面边线，但只能服务主体识别与平衡。
- 透视允许被压扁甚至改成准正视 / 准俯视 / 准侧视，只要主体识别与关系仍然成立。

## 边缘与材质

- 纸块边缘允许轻微不整齐、手工裁切感、圆钝转角或小幅毛边。
- 可有极轻的套印不准：相邻色块或刻线略微错位 1–3 像素感，但不能变成故障风。
- 可有掉墨、斑驳、细颗粒和轻微磨损，模拟丝网 / 版画印刷。
- 背景使用米白、暖白、浅灰米、纸本浅驼等安静底色，并让纸张纤维微弱可见。
- 禁止光滑塑料感、镜面高光、3D 凹凸、逼真阴影、照片滤镜和金属渲染。

## 色彩系统

- 从原图提炼 **2–4 种最有辨识度** 的颜色，必要时加一个中性色辅助。
- 综合色应 **鲜明但克制、明快但不刺眼**，避免灰脏、浑浊、糖果廉价感和过量彩虹配色。
- 一般构成：
  - 1 个主色承担主体最大块面；
  - 1–2 个辅助色形成层次与关系；
  - 1 个点睛色用于小面积识别点。
- 色块应是平涂或近似平涂，不使用大面积写实渐变；若需要层次，只做极轻微综合色明度差。
- 常见综合色倾向：暖黄 + 深蓝灰 + 橄榄绿；米黄 + 栗棕 + 深红；珊瑚红 + 靛蓝 + 奶白；森林绿 + 土黄 + 黑褐等。

## 构图

- 保持 **小尺度主视觉 / 章印感主视觉 + 大面积留白** 的关系。
- 主体可以居中、偏左、偏右、略贴底边或靠一侧形成落点，但始终清楚、稳定。
- 多主体时要有明确主次，不要形成多个互相争抢的焦点。
- 辅助元素极少且疏朗，不能把背景填满。
- 留白区域要“可呼吸”，不是为了空而空，而是服务版式平衡。

## 不同题材的映射

### 风景 / 建筑 / 城市

- 提取天际线、山形、树带、桥型、水岸、楼群高低节奏。
- 大建筑只保留标志轮廓与比例节奏，不做窗格细节堆砌。
- 天空、地面、水面常可压缩为少量静态留白与水平色带。

### 食物 / 静物

- 保留盘、杯、器皿轮廓与主要摆放关系。
- 奶油、果实、饼干、叶片等提炼成辨识度强的小纸片形，而不是保留照片质感。
- 食物层次可通过上下叠纸与少量色差表示，不做油润高光。

### 人物 / 动物

- 保留动作、头身关系、服饰大轮廓、花纹和毛色记忆点。
- 面部只做最小限度提示，不写实塑形。
- 头发、衣摆、耳朵、尾巴可被概括成少量韵律形色块。

### 植物 / 花卉

- 花瓣、叶片、枝条和花序先整体概括，再决定哪些作为大块、哪些作为刻线。
- 盛开方向和重心要保留，避免剪成完全均匀的装饰纹样。

## 版式与文字边界

- 示例图中的标题、英文副题、编号、年份、印章、署名只说明这种风格可兼容“小而轻的编辑式文字”。
- 但在通用 Skill 中，默认输出 **无文字**，以避免文字错误和模板感。
- 只有用户明确要求文字排版并提供文案时，才少量加入，并保持小、轻、克制。

## 与相近风格的边界

- **不是儿童剪贴画**：不能过于幼稚、随意或杂乱。
- **不是光滑矢量扁平插画**：边缘和质感要有纸艺与印刷感。
- **不是写实商业海报**：不保留真实高光、阴影和细密透视。
- **不是国潮模板海报**：不默认添加题字、印章、年份、格言或红框。
- **不是照片滤镜**：不能只是把照片降细节再叠纸纹。
- **不是复杂拼贴册页**：默认只建立一个清楚主视觉，不堆满小碎片。
