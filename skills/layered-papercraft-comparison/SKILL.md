# 立体剪纸风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的立体剪纸效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能从“真实照片 + 下方立体纸艺场景”的参考海报中提炼**立体纸艺部分的视觉语言**，适配 `visual-style-skills` 的统一工作流：真实原图由确定性拼版脚本保留，图像模型只生成与原图同画幅的立体剪纸效果图。不要在效果图内部再次复制真实照片，也不要强制改成 3:4 或上下分栏。

用户提供的风格案例只用于提炼风格，不是运行时依赖；不得打包参考图，也不得要求用户重复上传。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录全部原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写“识别摘要”：
   - 主体类别与数量；
   - 主轮廓、姿态、朝向和视觉重心；
   - 2–6 个不可丢失的结构、色彩、材质或环境识别点；
   - 原图中最重要的前后关系与叙事关系；
   - 原图的综合色温和 2–4 个值得保留的综合色。
4. 再写“纸艺场景映射”：
   - 指定唯一主视觉焦点；
   - 选择 2–5 个真正有助于说明地点、对象、生活状态或环境气质的辅助元素；
   - 决定哪些结构做成层叠纸片、哪些做成薄浮雕、哪些只保留剪影；
   - 规划基座长度、主体高低层次、前中后景的纸层关系，以及主要留白位置；
   - 决定哪些细节必须保留在主体上，哪些背景可压缩为更安静的陪衬。
5. 使用风格指南中的生成提示词，只生成当前输入对应的一张效果图。效果图必须保持原画幅比例和裁切方向，不生成内部“原图 + 纸艺”双栏。
6. 检查内容对应：主体身份、数量、姿态、朝向、关键结构和主要叙事关系仍可一眼对应；允许重新整理场景、压缩背景层次、减少杂讯，但不得更换主体或凭空添加与原图无关的大型装饰。
7. 检查风格：画面必须明显是**精致微缩立体纸艺场景**；主体及环境由层叠纸张、卡纸、少量木片 / 软陶感材料构成，具有可见纸层厚度、轻微切口、折边、细小毛边和真实手工误差；整体以柔和漫射光和细腻阴影呈现 macro photography 般的近距离质感。
8. 色彩保持柔和、通透、略去饱和：优先以浅粉蓝、雾蓝、天空蓝和空气感冷调蓝建立氛围，并以象牙白、奶油白、浅米色、柔和灰绿、鼠尾草绿和建筑中性色平衡；只允许小面积 dusty rose / muted blush 或同等克制暖色点缀。允许保留原图的关键身份色，但避免鲜艳塑料感。
9. 以下情况视为失败并针对偏差重试，最多 2 次：画面仍像普通照片；变成扁平矢量图或水彩插画；纸层不明显；主体像塑料 3D 模型、玩具摆件或电商渲染；阴影过硬；材质太光滑；背景被道具塞满；出现多个同等焦点；所有输入都套成相同基座、相同树木和相同云朵模板；添加与原图无关的地标或卡通元素；文字过大；出现品牌 Logo、水印或乱码文字。达到上限仍失败时继续其余输入，并准确说明未完成项。
10. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
11. 输出名优先为 `<原文件名去扩展名>_layered_papercraft_comparison.png`。同名时添加上传序号，绝不覆盖已有成品。
12. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 题材适配

- 建筑 / 地标：保持建筑主轮廓、比例、台阶、屋顶、开口、体块层级和标志性细部；建筑可承担主要高度与视觉重量，周边只保留少量树木、台地、道路、栏杆、云朵或飞鸟。
- 城市 / 街景：提取最关键的天际线、道路、线杆、店面、屋顶和生活符号，将复杂背景压缩为低密度纸层，保留城市感但不堆砌。
- 人物 / 日常生活：保留人物姿态、动作和与道具关系；五官与衣纹简化，更多依靠剪影、颜色和姿态表达。人物是主体时，可把环境缩为一条轻盈基座上的陪衬。
- 动物：保留物种、体型、姿态和主要花纹，用多层纸片体积与柔和阴影表达，不做毛发写实。
- 植物 / 花卉：保留花型、叶丛、枝条方向和生长节奏，可通过层叠花瓣、叶片与少量立杆建立纸艺纵深。
- 器物 / 交通工具：保留功能轮廓、关键零件、摆放方向与比例；可做成微型展陈式模型，基座周围仅留少量情境元素。
- 自然景观：保留山体、水面、海岸、云层、拱门、岩体等主形；可压缩为纸层山脊、台地或浮雕地形，但不得失去地点辨识度。

## 文字与排版

立体剪纸风可以包含极少量文字，但默认输出以稳定的无文字效果图为主：

- 用户明确提供可靠的地点、主体名称、主题词或标题时，可加入一个简短英文标题，优先置于景观基座下方留白区域。
- 标题可略带手写感、轻盈、精致，与微缩场景形成呼应；也可沿基座轻微排列。
- 可加入极少量小字，但不得伪造地名、年份、坐标、品牌或活动信息。
- 用户未提供可靠文字时，默认无文字，避免乱码、错字和模板化排版。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体身份、姿态和叙事关系可辨；下半部呈现精致微缩立体纸艺场景，具备纸层厚度、柔和阴影、轻盈基座和充足留白；无塑料 3D、无模板化复制、无儿童手工感、无过度拥挤；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
