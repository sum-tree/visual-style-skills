# 中国山水画对照图

把本轮上传的图片视为有序输入列表。每张输入只与它自己的山水画效果图配对，最终输出数量必须与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品，不额外呈现中间效果图。

用户提供的参考画只用于提炼风格，不是运行时依赖，不得复制其具体构图、山形、建筑、人物、印章或题款，也不得打包进本技能。

本技能保留的是原场景的**语义骨架与空间拓扑**，不是摄影轮廓：锁定前景、中景、远景的次序，主要对象的身份、相互关系、视觉流向和大致空间区域；允许山形、岸线、道路、树石和次要物体被概括、拉开、压缩、错落、融入云雾或重组为更适合山水画的形态。不得颠倒远近关系、改变主要对象的场景角色或凭空改成另一处风景。

## 选择风格模式

先理解用户对最终效果的实际要求，包括否定、纠正和上下文，不要只做机械关键词匹配。

- 明确要求“彩色、设色、着色、青绿、金碧、矿物色、color、colored、colour”时，选择 `彩色设色`，并只读取 [彩色设色指南](references/colored-ink.md)。
- 明确要求“黑白、纯墨、单色、墨色、monochrome、black and white、ink only”时，选择 `黑白水墨`，并只读取 [黑白水墨指南](references/monochrome-ink.md)。单独出现“中国水墨”或“水墨山水”且没有色彩要求，也按黑白水墨处理。
- 没有明确颜色要求时，默认 `黑白水墨`。
- 同一句中出现两类词时，遵循最后一个未被否定的明确选择；若仍无法判断，回落到黑白水墨。始终为每张输入选择一种模式，不擅自生成双版本。

无论选择哪种模式，都先读取 [构图与意境](references/composition-and-mood.md)，再只读取对应的色彩模式指南。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。无法取得每张图的独立路径时，在生成前说明阻塞；不要把多张原图一起交给图像生成工具。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 先在内部概括原图的近景、中景、远景、主要视觉落点、开合方向和疏密区域；把这些关系作为保留锚点，不把像素坐标、每条边线或所有琐碎物体写成硬锁定项。
   - 读取共用构图指南与已选模式参考文件，并使用其中的生成提示词。
   - 图像生成只负责当前效果图，不负责拼图、边框、标题或原图区域。
4. 检查效果图：画幅方向和比例与原图一致；主要场景语义、远近层级、对象角色、相互关系和视觉流向仍可对应。具体山形、岸线、道路宽窄、树石轮廓和次要设施不必逐像素一致；可以在所属空间层内适度移位、合并、概括或化入雾气，但主要视觉锚点仍应可辨。
5. 同时检查模式特征：
   - 黑白水墨必须让雾气、留白、墨色干湿和边缘的显隐共同塑造空间，近实远虚；不能只是照片去色、描边或铅笔素描。
   - 彩色设色必须以墨线、皴法和墨韵立骨，以克制的矿物色和暖纸色组织疏密；不能变成西方透明水彩、莫奈式碎笔、动漫或高饱和数字插画。
6. 以下情况视为失败并针对偏差重试，最多 2 次：仍按照片逐物体描摹；缺乏明显留白、雾气和虚实；所有边缘同样清楚；远近层次被压平；主要场景语义或对象关系改变；画幅比例超限；模式错误；出现原图没有的叙事主体、文字、题款、印章、签名、水印、Logo 或画框。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 黑白模式输出名优先为 `<原文件名去扩展名>_shanshui_ink_comparison.png`；彩色模式优先为 `<原文件名去扩展名>_shanshui_color_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- 风景、建筑与旅行照片：保留地貌、水域、道路和建筑之间的拓扑关系，允许以散点透视、三远法和开合疏密重新组织轮廓；现有山峰可夸张、合并或隐入雾气，但不凭空增加新的叙事地标。
- 人物或动物只是场景中的小主体时：可缩减为点景墨线或色点，只保留其场景作用、大致位置和朝向，不追求写实细节。
- 人物或动物是近景主体时：保持原主体为画面核心，以写意笔墨转换其轮廓和明暗；不得为了符合“山水”而凭空补造山峰、瀑布或古建筑。
- 城市、车辆或现代物体：保留其身份和与环境的关系，但可概括为少量墨线、块面或设色符号；小型路牌、护栏和路面标线可以合并减省，不改造成古代题材。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、印章、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；模式选择符合用户指令且未指定时为黑白水墨；构图与主体可对应辨认；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
