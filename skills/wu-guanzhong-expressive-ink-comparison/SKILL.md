# 吴冠中写意水墨对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的吴冠中式写意水墨效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能提炼的是一种现代水墨构成语言：以黑、白、灰建立重量和空间，以有提按、转折、枯润和断续变化的墨线组织运动，再以小面积高纯度彩点激活节奏。参考图中的江南白墙黑瓦、树木、拱桥、船、果实、人物和鸭子只是“点线面”如何工作的范例，不得把这些题材当成固定模板添加到其他照片。

用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制或打包参考图。参考中可见的题款、印章、签名和水印也不是风格素材，生成时一律排除。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。无法取得独立路径时，在生成前说明阻塞；不要把多张原图一起交给图像生成工具。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 先写“场景摘要”：列出主要物体、人物和动物的数量、身份或类型、姿态或朝向、总体位置、遮挡、空间顺序、关键轮廓及必须保留的叙事关系。
   - 再写“点线面映射”：指定 1–3 块乌黑或浓灰实面、承担主运动的书写性线组、连接空间的淡灰墨洗、连续纸白区域，以及 2–4 组红橙黄绿蓝彩点的大小、疏密和落点。彩点只能附着于原图已有对象或视觉节点。
   - 使用风格指南中的生成提示词。图像生成只负责当前效果图，不负责拼图、边框、标题或原图区域。
4. 检查内容：主体身份、数量、姿态或朝向、总体位置、主要空间流向和彼此关系均可对应。允许压扁透视、夸张曲线、合并重复纹理和轻微变形，但不得换主体、改变场景语义、删除关键现代物体或擅自古典化。
5. 检查风格：黑白灰形成明确骨架，纸白是主动形状；浓墨实面有视觉重量；墨线具有粗细、干湿、断续、速度和转折变化；灰洗连接空间但不过度渲染；高纯度彩点面积小、位置有节奏、聚散不均；点、线、面互相制衡，而不是普通黑白滤镜。
6. 以下情况视为失败并针对偏差重试，最多 2 次：场景摘要中的主要对象或叙事关系丢失；擅自添加江南民居、拱桥、船、树、果实、人物、鸭子或飞鸟；结果只是传统山水、工笔线描、普通水彩、照片滤镜或卡通；墨线粗细一致、僵硬描边或机械矢量化；整幅只剩灰雾而缺少浓墨实面；彩点均匀撒满、面积过大、颜色浑浊或与对象无关；出现油画厚涂、彩虹水彩流淌、3D 渲染、塑料质感；出现文字、题款、印章、签名、水印、Logo 或画框。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先为 `<原文件名去扩展名>_wu_guanzhong_ink_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 色彩选择

- 默认使用现代彩墨：黑白灰占主导，红、橙、黄、绿、湖蓝或钴蓝只作小面积彩点和短色线。
- 用户明确要求黑白时，取消彩点，以浓淡墨点和纸白保持节奏；不要因去色而变成单调灰色滤镜。
- 用户指定颜色时优先服从，但仍维持“少量高纯度色对比大面积黑白灰”的关系。

## 内容适配

- 风景、建筑与街巷：把山脊、屋面、道路、桥梁、岸线或天际线归纳为浓墨面和书写性长线，以纸白和灰洗压扁空间；不凭空改造成江南水乡。
- 树木与植物：主干和枝条作为有提按转折的线网，叶片、花果或光点可转成疏密不均的彩点，但对象数量与总体位置仍对应。
- 人物与动物：保持数量、身份、姿态、朝向和主要服饰或花纹，用简短墨线、黑白块和一处色点概括；中近景人物不能缩成无身份小点。
- 车辆、产品和现代设施：保留功能轮廓、关键部件和现代属性，以浓墨外形、纸白切口、灰洗与少量彩色节点表达；不得替换成舟船、古桥或传统器物。
- 复杂场景：先保留主空间流向和 1–3 个叙事焦点，再删减重复纹理。极简场景：减少墨面和彩点数量，不为“丰富”而添加元素。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、印章、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主要对象和空间关系可辨；效果具有现代点线面构成、黑白灰骨架、书写性墨线、纸白、浓墨实面和节奏性彩点，不照搬参考题材，不含题款印章；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
