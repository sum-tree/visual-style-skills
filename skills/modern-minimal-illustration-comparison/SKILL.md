# 现代极简插画对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的现代极简插画效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能提炼的是一种纯净、空灵、带微型叙事感的现代极简插画语言：用少量规则几何形、平面色层和细线概括对象，让大面积安静底色成为构图主体。参考图中的树、房子、人物、车辆和长椅只是形状与叙事方法的范例，不得把它们当成固定模板添加到其他照片。

用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制、打包或要求用户重新上传该参考。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。无法取得独立路径时，在生成前说明阻塞；不要把多张原图一起交给图像生成工具。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 先写“场景摘要”：列出主要物体、人物和动物的数量、身份或类型、姿态或朝向、相对位置、遮挡关系、空间顺序及必须保留的叙事关系。
   - 再写“极简映射”：确定一块连续的大留白、2–4 个前后景平面色层、2–6 个主要几何色块、必要的纤细结构线，以及哪些次要纹理可以删除。地平线可压低并简化透视，但不能改变主体身份或场景语义。
   - 使用风格指南中的生成提示词。图像生成只负责当前效果图，不负责拼图、边框、标题或原图区域。
4. 检查内容：主体数量、身份、姿态或朝向、主要轮廓、总体位置和彼此叙事关系均能对应。允许合并重复纹理、压扁景深和删除无关微小杂讯，但不能换主体、杜撰人物或道具，也不能把近景人物或产品缩成不可识别的小点。
5. 检查风格：存在一块主导画面的连续留白；物体以圆、椭圆、半圆、圆角矩形、简化坡面和剪影表达；前景、叙事带与远景呈浅空间分层；橙、黄、绿等 3–6 色清洁协调；色块边界清楚，渐变只在单个色块内部平滑受控；线条少、细、稳定。
6. 以下情况视为失败并针对偏差重试，最多 2 次：场景摘要中的主要物体或叙事关系丢失；擅自添加树、人物、房屋、车辆、长椅、飞鸟或装饰；留白不足、画面拥挤；透视和写实光影过强；物体仍保留照片级纹理；所有轮廓都被粗线包围；色块边界模糊或互相渗漏；出现水彩晕染、流淌、沉淀、返花、飞溅、蜡笔乱涂、3D 渲染、霓虹渐变或塑料质感；出现文字、题款、签名、水印、Logo 或画框。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先为 `<原文件名去扩展名>_modern_minimal_illustration_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- 风景与旅行场景：把天空或纸色作为最大留白，将地面、水面、远山压缩为 2–4 条简洁层带；道路、车辆、建筑、人物等只保留叙事所需轮廓和相对关系。
- 城市、建筑与室内：保留标志性外轮廓、开口和主要结构，把复杂立面、家具和背景合并为圆角块面或少量线条；不凭空改成乡村树景。
- 人物与动物：全身远景可转成小型剪影和一处服饰色点；中近景需保留身份、脸部朝向、姿态与主要花纹，以大轮廓和少量内部线概括，不能一律缩成微型人物。
- 产品与交通工具：保持功能轮廓、方向和关键部件，用规则平面色块表达；不得因极简化而更换品类、品牌形态或部件关系。
- 已经简洁的照片：减少色数和线数，不额外填充装饰。复杂照片：保留主叙事，删除重复纹理，但不删除关键主体。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主要对象和叙事关系可辨；效果具有巨大连续留白、规则几何色块、浅层分景、清晰边界、克制线条和受控渐变，无水彩失控效果；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
