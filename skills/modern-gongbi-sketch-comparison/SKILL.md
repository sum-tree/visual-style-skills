# 现代工笔写生对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的现代工笔写生效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能保存的是一套现代场景写生语言：尊重摄影构图和可识别细节，以细墨线、皴擦、淡矿物色与暖宣纸质感重新绘制。它与 `chinese-shanshui-comparison` 的写意造境不同，不使用散点透视重组空间，不让主要物体大面积消失在雾气中。

用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制、打包或要求用户重新上传该参考。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。无法取得独立路径时，在生成前说明阻塞；不要把多张原图一起交给图像生成工具。
2. 原始文件只读使用，不覆盖、不重命名，也不生成“相似原图”替代真实照片。
3. 每次只处理一张原图：
   - 使用 `referenced_image_paths: [当前原图绝对路径]`，不同时传入其他原图或风格参考图。
   - 使用风格指南中的生成提示词，并依据当前场景补充需要锁定的道路、建筑、车辆、人物、岸线、山体或地标。
   - 图像生成只负责当前效果图，不负责拼图、边框、标题或原图区域。
4. 检查效果图：画幅方向和比例、裁切范围、摄影视点、地平线、主体数量、主体位置、全局轮廓、道路与岸线走向、建筑与车辆结构、主要标志和空间层级均可对应。小纹理可手绘概括，但不得重新组织场景。
5. 同时检查风格：有明确但自然的细墨线和线性结构；淡青绿、花青、橄榄绿、赭石与暖纸色克制统一；写生细节清楚但没有照片滤镜感；阴影被简化为薄墨与平涂，不做写实三维渲染。
6. 以下情况视为失败并针对偏差重试，最多 2 次：构图或物体位置漂移；现代物体被古装化、删除或替换；山形和道路被写意重构；细节被大片雾气吞没；结果像西方透明水彩、莫奈油画、铅笔素描、动漫或照片滤镜；出现文字、题款、印章、签名、水印、Logo、画框或新物体。达到上限仍失败时继续其余输入，并准确说明未完成项。
7. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
8. 输出名优先为 `<原文件名去扩展名>_modern_gongbi_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
9. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容适配

- 山水、旅行与自然场景：保留真实山势、水岸、道路和地平线，以细线、薄墨与淡设色表现层次；不改造成散点透视的古典山水构图。
- 城市、建筑、车辆与产品：准确保留透视、几何结构、功能部件和现代属性，用工笔线描与克制平涂统一媒介。
- 人物与动物：保持数量、身份特征、姿态、朝向和主要花纹；五官、毛发、衣褶可用细线和分染概括，但不得更换身份。
- 天空、水面和空白区域：允许显露暖宣纸底与极淡洗色，但不能移动地平线或吞没主体。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、印章、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；原场景构图和现代物体准确；效果具有细墨线、淡设色、暖宣纸和克制写生质感；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
