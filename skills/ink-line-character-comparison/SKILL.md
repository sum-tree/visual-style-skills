# 线墨角色风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的线墨角色效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能不是把原主体直接“画成水墨”，而是先提炼其最核心的识别信息，再把这些信息转译成动物化角色。最终必须同时满足两点：第一眼是完整、灵动的动物角色；继续观察时能从轮廓、姿态、结构、配饰、色彩或气质中认出原主体来源。

用户提供的效果参考只用于提炼风格，不是运行时依赖；不得复制、打包或要求用户重新上传参考图。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录所有原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写出“识别核心”：
   - 主体类别与数量；
   - 最关键的外轮廓、方向和姿态；
   - 2–5 个最强识别结构或装饰；
   - 气质、情绪、身份感；
   - 1–2 个不可丢失的色彩记忆点；
   - 原图中真正有意义的相互关系。
4. 再写“动物化映射”：
   - 选择与原主体气质和结构最匹配的动物原型，不要默认变成猫；
   - 指定耳、尾、喙、须、爪、羽、角、鳍或身体曲线中承担识别转译的部位；
   - 把原主体的发型、服装、花瓣、屋顶、机械件、装饰或结构节奏转成动物身体、毛羽、配饰或剪影特征；
   - 只保留最有识别价值的 3–7 个视觉线索，其余删除。
5. 使用风格指南中的生成提示词，只生成当前图片对应的单张效果图。不要让生成工具制作原图对照、边框、标题或品牌标识。
6. 检查“转译后的神似”：角色必须明确是动物化生物，同时原主体来源仍可通过关键结构、气质、姿态、装饰或色彩隐约识别。若只是原物加耳朵/尾巴，或完全变成无关动物，都视为失败。
7. 检查风格：白色或暖白纸面主导；主体单一、居中或轻微偏置；墨黑轮廓具有明显提按变化和自然断续；存在少量干笔飞白、扫刷尾迹或纸面摩擦；体积主要靠黑白负形与极少灰阶组织；色彩极克制，默认只用少量朱红点色。
8. 以下情况视为失败并针对偏差重试，最多 2 次：直接照画原物而未动物化；所有主体都变成同一种猫；动物角色与原主体毫无识别联系；复杂背景或真实环境喧宾夺主；线条过于机械、均匀、矢量化；写实毛发和三维光影过强；大面积综合色；卡通贴纸感、动漫厚涂、3D 塑料感；添加文字、Logo、签名、水印、印章或品牌名称。达到上限仍失败时继续处理其余输入，并准确说明未完成项。
9. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
10. 输出名优先为 `<原文件名去扩展名>_ink_line_character_comparison.png`。同名时添加上传序号，绝不覆盖既有成品。
11. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 内容转译原则

- 人物 / 角色：提取发型、眼神、气质、服装结构、配饰、身份符号和动作，映射到动物脸型、耳尾、毛羽、姿态与少量配饰中。
- 花 / 植物：把花瓣、叶序、枝条、盛开姿态和综合色记忆映射到耳、尾、羽、冠、鬃毛或身体轮廓；不要直接给动物贴一朵花就结束。
- 建筑 / 场所：把屋顶、塔尖、拱券、窗格、层叠节奏和整体天际线转成动物背线、角冠、耳形、尾部与装饰节奏；不保留完整建筑背景。
- 器物 / 机械：把功能件、硬边结构、关节、转轴和节奏转成甲壳、角、爪、尾节、护具或身体折线；不要做“机器上长耳朵”的直接拼贴。
- 抽象概念：先提炼速度、压迫、轻盈、庄严、荒诞、温柔等气质和节奏，再选择动物原型与笔势，不凭空堆装饰。
- 已经是动物的输入：不强制换物种；保留原动物身份，并用线墨角色语言重构姿态、表情与识别特征。

## 品牌与文字

默认输出保持品牌中立、无文字。效果参考中的 VOXCAT Logo、签名、印章及品牌字样只作为案例版式信息，不属于本技能的通用风格语法，运行时不得自动复制或添加。只有用户明确要求使用其有权使用的品牌资产时，才可单独处理品牌叠加；不要把生成图伪装成参考品牌原作。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；动物化角色清晰可辨且仍保留原主体的核心识别信息；纸白留白充足；墨线有书写性、提按和飞白；黑白负形主导、色彩克制；无复杂场景、无机械矢量感、无品牌冒充；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
