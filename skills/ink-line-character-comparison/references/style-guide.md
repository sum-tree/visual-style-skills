# 线墨角色风风格指南

“线墨角色风”是一种先做概念转译、再做极简水墨造型的角色系统。它的关键不是“把任何东西画成猫”，也不是“在原物上加动物耳朵”，而是把原主体的身份信息拆解后，重新组织成一个独立成立的动物化角色。

## 视觉核心

- **动物化优先**：先确认新形象本身是一只完整的动物或动物化生物，再检查它是否携带原主体的来源信息。
- **转译后的神似**：原主体的识别信息应进入耳、尾、头冠、背线、毛羽、爪、须、喙、角、姿态、配饰或负形，而不是直接粘贴原元素。
- **极度减法**：删除照片级纹理、环境细节和大部分次要结构，只保留最强的 3–7 个视觉线索。
- **书法性线条**：线条有粗细、干湿、提按、停顿、断续与扫刷尾迹，不追求封闭、平滑和工程精度。
- **负空间参与造型**：纸白不是空背景，而是动物腹部、脸部、四肢之间、耳内或尾部之间的重要形状。
- **单体角色**：默认一张图只建立一个主角色。若原图有多个同等重要主体，可保留多角色关系，但仍须保持稀疏、无复杂场景。

## 从原主体提取什么

先只回答以下问题，不要立即决定画什么动物：

1. 外轮廓最特别的地方是什么？
2. 原主体最容易被记住的 2–5 个结构是什么？
3. 是轻盈、威严、顽皮、冷峻、笨拙、机械、柔软，还是其他气质？
4. 有哪些配饰、服装、花瓣、屋顶、机械件、纹样或符号，一旦删除就会失去身份？
5. 哪一种颜色是记忆点，而不是普通综合色？
6. 眼神、动作、方向、重心和节奏是什么？

最终只保留能改变“认不认识它”的信息。

## 动物原型选择

不要默认猫。根据源主体气质和形态选择更合适的动物：

- 细长、灵敏、锐利：狐、鹿、兔、鹭、蛇等长线型动物。
- 圆润、憨厚、厚重：熊、獭、犬、熊猫、海豹等块面型动物。
- 威严、装饰复杂：大型猫科、孔雀、鹿、鹰、天鹅等可承载冠饰和仪式感的动物。
- 机械、硬边、速度感：甲虫、犀、狼、隼、蜥蜴等结构清晰的动物原型。
- 植物、花朵、柔软主题：兔、鹿、蝶、鸟、猫科等适合将花瓣和枝叶转成耳、羽、冠或尾的动物。
- 抽象概念：先依据“速度 / 沉静 / 荒诞 / 权威 / 温柔 / 紧张”等情绪选物种，再决定结构。

物种只是载体。不得因为品牌案例里常见猫系元素，就让所有主体最终变成同一只猫。

## 动物化映射方法

### 人物与角色

- 发型 → 耳形、鬃毛、头顶毛束或冠羽。
- 服装大轮廓 → 胸腹负形、背线、尾部轮廓或披挂结构。
- 首饰与配件 → 极少量挂饰、颈饰、头饰或爪部装饰。
- 眼神和气质 → 眼形、头部仰俯、脖颈曲线、身体重心。
- 武器或身份器物 → 优先转为角、尾、翅、护甲节奏；必要时才保留极简道具。

### 花与植物

- 花瓣 → 耳、冠、尾羽、鬃毛或背部节奏。
- 枝叶 → 尾巴、须、腿部线势或外轮廓延伸。
- 盛开 / 垂落 → 身体姿态和重心。
- 花色 → 单一克制点色，不保留综合色铺满。

### 建筑与场所

- 屋顶 / 塔尖 → 耳、角、头冠。
- 拱券 / 门洞 → 胸腹负形、眼眶或身体内部留白。
- 重复窗格 → 少量斑纹或配饰节奏，不逐格照搬。
- 天际线 → 背部轮廓或尾部大曲线。

### 器物与机械

- 旋钮 / 轴 / 齿轮 → 关节、眼、角根或装饰节点。
- 壳体 → 身体主剪影。
- 把手 / 管路 → 尾、须、角或脖颈线。
- 硬边节奏 → 甲壳、爪、护甲或折线型背脊。

## 线条语法

- 使用 3 类主笔触：粗重承重笔、灵活轮廓笔、极细提示线。
- 轮廓不必闭合；让纸白穿透主体。
- 粗重笔触用于背、尾、耳根、肩胛等重量区；不要平均分布。
- 细线用于胡须、眼角、爪、装饰连接、少量结构暗示。
- 保留轻微抖动、断裂、毛边、枯笔和不对称。
- 允许一笔完成长耳、尾、背线或脖颈，形成明显 gesture stroke。
- 禁止统一线宽、Bezier 式完美曲线、图标化描边和封闭矢量轮廓。

## 干笔、飞白与墨块

- 干笔飞白主要放在尾、背、耳、肩、腹部外沿等大动作区域。
- 飞白要顺着身体运动方向，不能随机撒纹理。
- 墨块可以有不均匀边缘和纸纹漏白，但不能变成泼墨背景。
- 灰色只作为少量中间层，默认仍以墨黑与纸白建立主要结构。

## 构图

- 背景使用白色、暖白或极浅纸色，不建立真实场景。
- 主体通常占画面约 55%–78%，四周留有明显呼吸空间。
- 可居中，也可轻微偏置以强化尾巴、耳朵或视线方向。
- 允许一两处小型装饰性墨点、叶片形或气泡形，但只能服务平衡，不可发展成叙事背景。
- 不使用真实地平线、室内环境、复杂道具陈列、光影场景或景深。

## 色彩

- 默认：纸白 + 墨黑 + 极少量朱红。
- 朱红只用于眼、耳尖、腮、嘴、爪、头冠、挂饰、花性结构或一个识别节点。
- 点色面积通常不超过主体综合色面积的 8%–12%。
- 若原主体有不可替代的综合色身份，可用一种低饱和源色替代朱红作为唯一第四色，例如灰蓝、玉绿或暗金；不要同时使用多个综合色。
- 不做综合色渐变、霓虹综合色、综合色光效或综合色背景。

## 表情与角色感

- 允许适度夸张眼睛、耳朵、尾巴、脖颈和身体比例。
- 表情要克制而有机智感，不做幼儿卡通式大笑、夸张表情包或萌系贴纸。
- 荒诞感来自比例、姿态与身份转译，不来自堆砌奇怪道具。
- 角色应有“独立艺术出版物中的单幅角色插画”感，而不是手游角色立绘或商业吉祥物 3D 渲染。

## 与相近风格的边界

- **不是传统工笔**：不追求细密勾线和综合色层层罩染。
- **不是泼墨写意**：不依赖大面积随机墨云，主体轮廓和角色识别必须清楚。
- **不是动漫水墨滤镜**：不是把已有角色保留不动再叠纸纹与墨边。
- **不是矢量 Logo**：不使用统一粗细、几何闭合轮廓和机械平滑曲线。
- **不是猫化模板**：耳朵、尾巴和猫眼只是可选语言，不得覆盖原主体身份。
- **不是品牌复刻**：不复制参考图中的 VOXCAT Logo、签名、印章或品牌字样。

重试时只补充观察到的具体偏差。例如：“当前只是人物加兔耳，动物化不充分；把长发转成两条长耳和后背扫刷线，把披风转成大尾部负形，删除原人物躯干结构；同时减少综合色与背景装饰。”
