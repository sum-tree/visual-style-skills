# 艺术明信片风对照图

把本轮上传的所有图片视为有序输入列表。每张输入只与它自己的艺术明信片效果图配对，输出数量与输入数量相同、顺序一致。不同原图绝不共用画布，最终只呈现对照成品。

本技能从“上方真实照片 + 下方艺术明信片插画”的参考海报中提炼**下方明信片视觉语言**，适配 `visual-style-skills` 的统一工作流：真实原图由确定性拼版脚本保留，图像模型只生成与原图同画幅的艺术明信片效果图。不要在效果图内部再次复制真实照片，也不要强制改成 3:4 或内部上下分栏。

用户提供的风格案例只用于提炼风格，不是运行时依赖；不得打包参考图，也不得要求用户重复上传。生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录全部原图的本地绝对路径，不按文件名或文件系统顺序重排。原图只读使用，不覆盖、不重命名。
2. 每次只处理一张原图，不同时向图像生成工具传入其他原图或风格参考图。
3. 生成前写“识别摘要”：
   - 主体类别与数量；
   - 主轮廓、姿态、朝向和视觉重心；
   - 2–6 个不可丢失的结构、综合色或场景识别点；
   - 原图中最重要的空间 / 叙事关系；
   - 最值得保留的 2–4 种综合色。
4. 再写“明信片映射”：
   - 选定唯一主视觉焦点；
   - 决定插画保留哪些主体 / 环境轮廓，删除哪些低价值纹理；
   - 把复杂真实细节压缩成适合丝网印刷的块面、线刻和颗粒；
   - 规划插画在画面中的小尺度位置，使四周保留大量象牙白留白；
   - 决定是否需要单枚蓝黑圆形邮戳作为版式平衡；
   - 用户提供可靠文字时，确定一个短标题和底部地点 / 日期字段；否则默认无文字。
5. 使用风格指南中的生成提示词，只生成当前输入对应的一张效果图。效果图必须保持原画幅比例和裁切方向，不生成内部“照片 + 插画”双栏。
6. 检查内容对应：主体身份、数量、姿态、方向、主要轮廓和关键叙事关系仍可一眼对应；允许删除写实纹理、简化背景和弱化次要对象，但不得更换主体、改变场景语义或凭空添加无关地标。
7. 检查风格：背景必须以象牙白 / 暖白旧纸为主；主体插画小而清楚、无边框、周围留白充足；综合色压缩为 2–4 种克制不饱和色；具有丝网印刷、轻微网点、低保真套印与纸面颗粒，但不能脏乱。
8. 以下情况视为失败并针对偏差重试，最多 2 次：画面仍像照片；变成平滑矢量或写实插画；插画过大挤满页面；色彩超过 4–5 种且杂乱；纸张过黄、污渍过重；出现厚重投影、卷角、立体样机或邮票；出现多个邮戳 / 多余印章；文本乱码、重复或喧宾夺主；出现 Logo、水印、二维码、品牌标识或商业旅游海报套版。达到上限仍失败时继续其余输入，并准确说明未完成项。
9. 使用 `scripts/compose_comparison.py` 将未经修改的真实原图与合格效果图确定性拼版。不要让图像模型生成原图区域。
10. 输出名优先为 `<原文件名去扩展名>_art_postcard_comparison.png`。同名时添加上传序号，绝不覆盖已有成品。
11. 完成一张后自动继续下一张，不在批处理中途请求确认。全部完成后，只按上传顺序呈现最终高清 PNG。

## 题材适配

- 城市 / 建筑 / 地标：保留天际线、桥型、塔体、屋顶、开口、道路、水岸等最具识别性的结构；将窗格和复杂材质压缩为印刷色块或线刻节奏。
- 室内 / 展览 / 空间：保留墙面、画作、家具、灯光分布和人物位置关系，但把真实空间简化成小型编辑插画，避免写实透视细节堆积。
- 自然景观：保留山形、水面、云层、海岸、岩体、树线等主要轮廓，通过 2–4 色印刷块面建立层次。
- 人物 / 日常生活：保留姿态、服饰综合色、动作及与道具关系，五官和衣纹极简；不转成卡通大头人物。
- 动物：保留物种、姿态、体型和主要花纹，用综合色块与少量轮廓线表现，不做毛发写实。
- 器物 / 交通工具：保留功能轮廓、方向、关键零件和物体间关系，可适度图形化但不能换品类。

## 邮戳与文字

- 默认允许 **0 或 1 枚**低调、磨损、蓝黑色圆形邮戳；它只是版式元素，不应遮挡主体。
- 邮戳不得包含可误导的真实邮政机构、品牌或精确邮资信息；内部微字可保持抽象、不可读或省略。
- 不添加邮票、二维码、额外印章、作者签名或品牌 Logo。
- 用户提供可靠的主体名称 / 地点 / 日期时，可加入：一个小号复古打字机标题，以及底部类似 `PLACE · DATE` 的简洁字段。
- 用户未提供可靠文字时，默认无文字；不要自行编造地点、日期、坐标或展览信息。
- 若需要文字，保持小、轻、克制、宽松，不制作大标题栏。

## 确定性拼版

从技能目录运行：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

若系统提供绑定的 Python 运行时，优先使用该解释器。脚本需要 Pillow，并固定执行：

- 横版原图在上、效果图在下；竖版或正方形原图在左、效果图在右。
- 两图显示尺寸与画幅比例相同；原图不缩放、不裁切、不调色，效果图只在比例通过校验后等比调整到原图尺寸。
- 背景为 `#F7F4EE`；四周留白和两图间距均约为单张图短边的 4%。
- 外沿描边为 `#E5E0D7`，粗细约为短边的 0.125%。
- 不添加阴影、标题、编号、标签、说明、装饰线、题款、签名、Logo 或水印。

效果图与原图的画幅比例相对偏差不得超过 0.5%。超限时重新生成效果图，不得裁切、拉伸、压缩或加边伪装匹配。

## 完成检查

输入 N 张时输出恰好 N 张；每张成品只含一张真实原图及其对应效果图；主体可辨；效果图具有象牙白旧纸、小尺度无边框丝网插画、2–4 色克制配色、轻微印刷噪点与大量留白；邮戳最多一枚且低调；无邮票、无样机、无厚重阴影、无多余印章、无模板化商业旅游海报；两图完整、等尺寸、无重叠；方向、顺序、命名正确；全部为高清 PNG。
