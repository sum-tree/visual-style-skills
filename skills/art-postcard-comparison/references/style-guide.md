# 艺术明信片风风格指南

“艺术明信片风”是一种把真实照片中的主体，重新压缩成**小尺度复古丝网印刷插画 + 象牙白旧纸 + 大面积留白 + 极少编辑文字 / 邮戳**的收藏级明信片视觉。它的重点不是模拟普通旅游纪念品，而是形成温暖、安静、克制、具有独立出版物和艺术杂志气质的纸本设计。

## 核心视觉语言

- **小图、大留白**：插画通常只占画面约 35%–55%，四周有大量象牙白或暖白纸面。
- **主体一眼可辨**：即使高度简化，也要保留最重要的外轮廓、方向、姿态和结构关系。
- **丝网印刷 / 低保真印刷感**：综合色平、层次少，带轻微颗粒、网点、掉墨和套印偏差。
- **2–4 色系统**：从原图提取综合色并压缩成少量克制综合色，避免全彩图像感。
- **编辑式克制**：邮戳、标题、地点与日期都只是小型辅助，不能抢主体。
- **纸本温度**：背景可见极轻纸纤维、微小综合色不均和少量老化感，但整体保持干净。

## 与“旅行海报风”的区别

“旅行海报风”强调半色调、ASCII、撕裂照片、技术构造线和档案建筑感；“艺术明信片风”更安静、更小尺度、更纸本化：

- 不使用密集 ASCII；
- 不使用复杂技术图线；
- 不使用大面积照片碎片拼贴；
- 插画更像 2–4 色丝网版画；
- 版面更留白、更轻、更像独立出版明信片。

## 与“剪纸拼贴风”的区别

“剪纸拼贴风”强调彩纸边缘、民艺色块和纸片拼接；本风格强调**印刷出来的图像**：

- 综合色块像丝网印刷 / 孔版印刷，不像剪下来的纸片；
- 不强调纸层厚度与剪切边；
- 允许轻微印刷错位、噪点和半色调；
- 保持更复古、编辑、档案式的明信片气质。

## 内容提炼

生成前先回答：

1. 最重要的主体是什么？有几个？
2. 哪些轮廓一删就无法识别？
3. 哪些位置关系或动作关系必须保留？
4. 原图中最能代表它的 2–4 种综合色是什么？
5. 哪些背景细节可以删除？
6. 插画应该横向展开、竖向集中还是偏置？
7. 最大留白应该放在哪里？

## 插画造型

- 使用简化剪影、平面综合色块、少量线刻和粗细克制的轮廓线。
- 建筑只保留主轮廓、屋顶、桥塔、窗列节奏和关键结构，不逐格描绘。
- 人物用姿态、服饰综合色和与环境的关系表达，五官简化。
- 室内用墙面、画框、家具、栏杆、灯具等主结构建立空间，不保留复杂材质。
- 水面、天空、草地、山体可用粗颗粒综合色面和稀疏纹理组织。
- 不使用真实阴影、镜面高光、复杂渐变和照片级细节。

## 印刷质感

允许：

- 轻微 silk-screen / stencil print 颗粒；
- 细小半色调点；
- 低保真综合色边缘；
- 1–2 像素感的轻微套印偏差；
- 温和噪点、掉墨和纸面纤维；
- 局部综合色不完全均匀。

禁止：

- 大面积脏污、咖啡渍覆盖；
- 强烈 grunge；
- 数码故障、RGB 分离；
- 纸张卷角、折痕样机、厚投影；
- 把图做成放在桌面上的实体明信片 mockup。

## 色彩系统

- 从原图提炼 **2–4 种**最具识别度的综合色。
- 综合色整体略去饱和、轻微褪色，但不能灰脏。
- 背景使用象牙白、奶油白、暖纸白或很浅米色。
- 常见组合：
  - 灰蓝 + 砖红 + 暖白；
  - 靛蓝 + 柔和橙 + 灰米；
  - 鼠尾草绿 + 土黄 + 暗红；
  - 海军蓝 + 雾蓝 + 灰褐；
  - 深青 + 沙色 + 综合色红点。
- 不使用荧光综合色、霓虹综合色或高饱和糖果综合色。

## 留白与比例

- 主插画通常占画面宽度约 45%–75%，高度约 30%–55%，按主体最佳可读性调整。
- 至少保留一块大面积连续空白，不让插画铺满整页。
- 插画默认位于中下部、居中偏置或水平展开；可根据主体方向调整。
- 留白承担高级感，不应被无意义图标、边框和说明填满。

## 邮戳

- 默认最多 **1 枚**圆形蓝黑色邮戳。
- 位置宜在右上、右侧或与插画边缘轻微相交处，以平衡版面。
- 邮戳需磨损、低对比、有旧印刷质感。
- 不放真实邮政 Logo、邮票面值、精确邮路或可误解的官方标识。
- 不追加第二枚、第三枚装饰印章。

## 文字

用户明确提供可靠文案时才加入文字：

- 一个小号标题：主体名 / 场所名 / 主题词；
- 底部一行 `PLACE · DATE` 式元数据；
- 可用复古打字机 / 等宽字体气质。

规则：

- 字号小、字距舒展、低对比；
- 不要重复标题；
- 不要自动编造地名、日期、坐标；
- 不要在邮戳内部生成大量文字；
- 文本只是编辑元素，不是主视觉。

## 明确避免

- 传统商业旅游海报的大标题；
- 邮票、二维码、Logo、水印；
- 多个邮戳和装饰章；
- 外边框、厚重投影、卷角；
- 立体卡片样机；
- 水彩、油画、3D、矢量企业插画；
- 密集说明文字和信息图式标签。

重试时只补充已经观察到的偏差。例如：“当前插画占比过大且像平滑矢量图；缩小到画面高度约 42%，增加象牙白留白，综合色压缩到灰蓝、砖红和暖白三色，并加入轻微丝网颗粒与一枚低对比蓝黑邮戳。”
