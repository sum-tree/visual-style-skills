# 简约留白对照图

把本轮待处理照片视为有序列表，逐张生成效果、逐张拼版。输入 N 张就输出 N 张独立高清 PNG，保持上传顺序，不把不同照片放到同一画布。

本风格提炼参考下半部分的视觉语言：景物如记忆片段般浮现在暖白空场。上半部分原图对照区由脚本从未经修改的源文件确定性合成，图像模型只生成效果区域。参考中的雪山、湿地与英文题名只是示例，不能移植到无关照片。参考图不是运行时依赖，不打包、不要求重新上传。

生成前读取 [风格指南](references/style-guide.md)。

## 执行流程

1. 按上传顺序记录每张原图的本地绝对路径；原始文件只读，不覆盖、不重命名。无法取得独立源文件路径时说明阻塞，不以模型重画代替原图。
2. 每次仅将当前原图交给图像生成工具，使用 `referenced_image_paths: [当前原图绝对路径]`，不混入其他输入或风格参考。
3. 写“意象摘要”：只选源图中少量代表色、主要方向、轻重和大致左右关系；明确舍弃哪些对象与细节，不将逐项身份、数量、部件或完整轮廓作为保真清单。
4. 写“留白映射”：近乎均匀暖米白空场约占整个效果画幅 85%–92%；真正着色的景物约占 8%–15%，按笔触与色片面积计，不按外接矩形计。将源图压缩为中下部 3–5 个分离片形、极薄色痕或淡影，使用 2–3 种低饱和代表色。每片仅一两处方向转折，片间保留大段纸色。允许省略次要对象、合并重复对象、断开轮廓、压平景深；人物、动物与产品同样采用意象概括，不为还原五官零件而减少留白。不得添加无关题材。
5. 使用风格指南提示词，只生成保持源图画幅比例与裁切方向的一张完整效果图。效果内部不再次生成照片、上下对照或外框。
6. 默认无文字。用户要求参考中的诗题效果时，在效果区域底部留白放一行小号深灰衬线题名；优先使用用户原文，否则可依据可见景物写 3–6 词英文诗题，不杜撰地点、日期、作者或坐标。不固定复用参考题名。
7. 检查形色来源与方向呼应源图即可，不要求逐物可辨或完整轮廓。暖白应连续、近乎均匀；实际有色面积小，片形薄、平、断续。完整山脊、岩纹、雪纹、枝叶、窗格、五官、零件、反射或体积明暗被具体描绘，均说明过于具象；连续地景、完整物体剪影、缩小完整照片、满幅淡雾、留白不足、粗描边、飞溅、纸艺投影或乱码也属失败。只针对偏差重试，最多 2 次；仍失败时报告未完成项并继续其他输入。
8. 使用本技能内的 `scripts/compose_comparison.py` 确定性拼版，禁止图像模型生成原图区域。
9. 输出 `<原文件名去扩展名>_minimal_negative_space_comparison.png`。同名追加上传序号，不覆盖已有成品。全部完成后按上传顺序只呈现最终高清对照 PNG。

## 确定性拼版

从本技能目录运行，需要 Pillow；若有绑定的 Python 运行时，优先使用：

```powershell
python scripts/compose_comparison.py --original <原图> --effect <效果图> --output <最终PNG>
```

- 横图原图在上、效果在下；竖图与正方形原图在左、效果在右。
- 原图不缩放、不裁切、不调色。效果图比例校验通过后调整至原图像素尺寸；两图等尺寸、完整且不重叠。
- 画幅比例相对偏差不得超过 0.5%；超限重新生成，不裁切、拉伸或加边伪装匹配。
- 背景 `#F7F4EE`，四周留白和间距约为原图短边的 4%；描边 `#E5E0D7`，约为短边的 0.125%。
- 拼版不添加文字、阴影、编号、标签或装饰。可选诗题仅属于生成的效果区域。

## 完成检查

数量顺序对应；每张只含真实原图及自己的效果；源文件未修改；效果以约 85%–92% 暖白空场和 3–5 个高度概括片形为主，少量形色与方向线索来自源图；无完整具象场景、逐物还原或满幅淡雾；无复制参考题材、额外地标、印章、Logo 或水印；题名模式符合用户选择；全部为高清 PNG。
